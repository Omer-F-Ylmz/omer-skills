Let Claude (or any LLM) actually watch a video: scene-aware, deduplicated
frames + a transcript, from a URL or a local file.

positional arguments:
  source                Video URL (YouTube, Instagram, ...) or a local file
                        path

options:
  -h, --help            show this help message and exit
  -o, --out OUT         Output directory (default: ./crv-out)
  --overwrite           Replace a previous analysis living in the output
                        directory (without this, a non-empty output dir is
                        refused to avoid mixing videos)
  --scene SCENE         Scene-change sensitivity 0-1, lower = more frames
                        (default: 0.30)
  --fps-floor, --min-frame-interval FPS_FLOOR
                        SECONDS PER FRAME, not fps — guarantee at least one
                        frame every N seconds (default: 1.0; --min-frame-
                        interval is an alias)
  --max-frames MAX_FRAMES
                        Cap total frames (default: auto — scales with
                        duration, clamp(150, seconds*1.5, 600))
  --from TIMECODE       Analyse only from this point (90, 1:30, 0:01:30.5).
                        Reported timestamps stay source timecodes, not window-
                        relative
  --to TIMECODE         Stop analysing here. With --from, the frame budget and
                        the transcript follow the window instead of the whole
                        file
  --frame-width PX      Width of extracted frames, aspect kept (default: 640).
                        Raise it when the meaning is small text — terminals,
                        spreadsheets, dense dashboards. Larger frames multiply
                        output size and model cost
  --adaptive            Adaptive scene detection: catches slow morphs (2-3s
                        squash/stretch, gradual pans) a fixed threshold
                        misses, by comparing each frame against its rolling
                        neighbourhood instead of a constant
  --text-anchors        Force extra frames at subtitle-cue timestamps (sidecar
                        .srt/.vtt or embedded track) — for videos where
                        meaning changes faster than pixels: burned-in
                        captions, lecture slides, screen recordings. At most
                        one forced frame per second; scene detection unchanged
  --export {llc}        Also export the analysis for other tools. 'llc' writes
                        a lossless-cut project (highlights.llc): every
                        detected scene becomes a cut segment — open it, keep
                        the highlights, delete the rest (issue #10)
  --speakers            Label who spoke when: offline speaker diarization
                        (sherpa-onnx, no account/token needed — models auto-
                        download on first use). Transcript lines get
                        [SPEAKER_00]-style prefixes; needs: pip install
                        'claude-real-video[speakers]'
  --lang LANG           Whisper language, e.g. en / zh / auto (default: auto)
  --cookies COOKIES     Netscape cookie file for sites that need login (your
                        own, authorised use only)
  --cookies-from-browser BROWSER
                        read login cookies straight from your own browser —
                        chrome, safari, firefox or edge. For sites that need
                        login (your own account only)
  --yt-dlp-arg ARG      pass a raw yt-dlp option straight through; repeat for
                        each token, e.g. --yt-dlp-arg=-S --yt-dlp-arg=res:1080
                        to skip pulling a 4K master, or --yt-dlp-arg=--remote-
                        components --yt-dlp-arg=ejs:github for YouTube JS
                        challenges. Use this instead of editing your machine-
                        wide yt-dlp config, which would change behaviour for
                        every other tool on the machine
  --no-transcribe       Skip audio transcription
  --viewer              also write viewer.html — browse the video, keyframes
                        and transcript in one local page (double-click to
                        open)
  --whisper-model {tiny,base,small,medium,large,turbo}
                        Whisper model for transcription (default: base — fast
                        and small, so the first run isn't a 3GB wait. Want
                        sharper? --whisper-model turbo: a pruned large-v3,
                        much faster than large with a minor quality trade-off
                        (one-time 1.6GB download). medium/large also available
                        — bigger models download more)
  --dedup-threshold DEDUP_THRESHOLD
                        Percent of pixels that must change for a frame to
                        count as new; higher = fewer frames kept (default: 8)
  --dedup-window DEDUP_WINDOW
                        Compare each frame against the last N kept frames, so
                        a shot the model already saw doesn't come back after a
                        cutaway (1 = classic consecutive-only, default: 4)
  --report              Keep dropped frames in ./dropped and write report.html
                        visualising every keep/drop decision, for tuning the
                        threshold
  --why WHY             Why you are watching, e.g. --why "find the pricing
                        strategy" — written into MANIFEST.txt so the model
                        analyses with that lens instead of producing a generic
                        summary
  --grid                Also tile the kept frames into 3x3 contact sheets
                        (./grids) — consecutive frames side by side help the
                        model follow motion and progression instead of
                        guessing between stills
  --kb DIR              Also save the analysis as a dated markdown note into
                        this knowledge-base folder (e.g. your Obsidian vault)
  --keep-audio          Also save the full original soundtrack (music +
                        speech) as audio.m4a, for models that can listen to
                        audio (Gemini, GPT-4o, ...)
