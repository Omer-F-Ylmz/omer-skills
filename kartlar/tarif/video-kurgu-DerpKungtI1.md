# video-kurgu (DerpKungtI1)

**Amaç:** Bir konu veya anahtar kelimeye dayalı olarak otomatik video üretmek.
**Araçlar:** Claude Code (AI platformu), MoneyPrinterTurbo (Python tabanlı otomatik video üreten araç), Pexels API (ücretsiz video materyali sağlayan platform), FFmpeg (video kodlama ve düzenleme için kullanılan araç)

**Adımlar**
1. [] Kullanıcı, MoneyPrinterTurbo'nun GitHub'dan indirilir ve kurulumu yapılır. (Ekran görüntüsünde v1.3.8 sürümü gösteriliyor.)
2. [] Kullanıcı, Pexels API anahtarını alarak video materyalinin kaynağını sağlar.
3. [] Kullanıcı, Claude Code platformuna girerek bir konu veya anahtar kelime girer. (Örnek: 'The future of everyday robotics').
4. [] MoneyPrinterTurbo, Claude Code tarafından otomatik olarak script yazılır, materyal aranır, seslendirme, alt yazı ve müzik eklenir.
5. [] Kullanıcı, MoneyPrinterTurbo'nun ayarlarını yapılandırır: video formatı (dikey/geniş), seslendirme hızı, müzik seviyesi, alt yazı ayarları gibi.
6. [] MoneyPrinterTurbo, kullanıcıya hazır video, script, seslendirme, alt yazı ve müzik ile birlikte sunulur.

**Prompt/kod/ayar:** Paste one line into Claude Code with your topic (e.g., 'The future of everyday robotics')
**Sonuç:** Tamamen otomatik olarak üretilen video (script, seslendirme, alt yazı, müzik ve materyal dahil).
**Bizde (öneri, modelden):** Kurulu araçlarla nasıl yapılır: Claude Code veya benzer AI platformları kullanılarak MoneyPrinterTurbo'nun API'si çağrılır ve kullanıcıdan alınan konu ile otomatik video üretimi sağlanır.
**Daha iyi (öneri):** Kullanıcıya daha fazla özelleştirme seçeneği sunmak için MoneyPrinterTurbo'nun ayarlarını daha detaylı yapılandırma ve kullanıcıya daha fazla materyal seçeneği sunmak.
