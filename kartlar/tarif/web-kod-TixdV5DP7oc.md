# web-kod (TixdV5DP7oc)

**Amaç:** Ücretsiz araçlarla $10.000'lık bir ajans web sitesi kalitesinde tasarım yapmak.
**Araçlar:** Emil Kowalski Motion Skill (flüssige Animationen), Impeccable Skill (23 komutla layout, yazı tipleri ve boşluk optimizasyonu), Taste Skill (standart tasarımlardan uzak durma), Figma Connector (Figma entegrasyonu), Playwright (otomasyon ve test)

**Adımlar**
1. [0:00-0:02] Claude'ın web tasarım alanındaki etkisini vurgulayarak kullanıcıyı ilgi çekmek.
2. [0:02-0:09] Standart AI web tasarım çıktılarının sıkıcı olduğunu ve bu durumun nasıl çözülebileceğini anlatmak.
3. [0:15-0:23] Emil Kowalski tarafından geliştirilen Motion Skill'i kullanarak animasyon ve yüksek kaliteli görsel deneyim sağlama.
4. [0:23-0:28] Impeccable Skill'i kullanarak layout, yazı tipleri ve boşlukları optimize etme.
5. [0:28-0:35] Taste Skill'i kullanarak standart tasarımlardan uzak durma ve AI'nin 'tad' yeteneğini kullanarak tasarımın daha özgün olmasını sağlamak.
6. [0:35-0:38] Figma ve Playwright entegrasyonunu yaparak AI'nin tasarım ve test sürecini otomatikleştirme.
7. [0:38-0:43] AI'nin tasarımın tasarlanmasını, kodlanmasını, gerçek bir tarayıcıda açılmasını ve test edilmesini otomatik olarak gerçekleştirme.
8. [0:43-0:47] Kullanıcıdan tasarım talimatları alarak birkaç dakika içinde canlı bir web sitesi oluşturma.

**Prompt/kod/ayar:** Claude Code + Figma Connector + Playwright entegrasyonu
**Sonuç:** AI'nin kullanıcıdan talimat alarak $10.000'lık ajans web sitesi kalitesinde tasarım ve kodlama yapması.
**Bizde (öneri, modelden):** kurulu araçlarla nasıl Claude Code ve Figma entegrasyonu yapılırsa, Playwright ile test otomasyonu sağlanırsa, AI'nin tasarım ve kodlama sürecini tamamen otomatikleştirmek mümkün.
**Daha iyi (öneri):** AI'nin daha fazla özelleştirilebilir skill ve entegrasyon desteği sunmasıyla daha hızlı ve daha kaliteli sonuçlar elde edilebilir.
