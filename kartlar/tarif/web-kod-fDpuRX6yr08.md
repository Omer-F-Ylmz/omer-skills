# web-kod (fDpuRX6yr08)

**Amaç:** Websiteleri API'ye dönüştürmek ve verileri kolayca erişilebilir hale getirmek.
**Araçlar:** HAR dosyası kaydı, AI agent, Konfigüre edilmiş model (Python/JavaScript/TypeScript/Go/Java/C#/PHP/Ruby/C/PowerShell)

**Adımlar**
1. [] Kullanıcı bir websitesi ve hedefi (örn. 'fetch all Apple jobs') girer.
2. [] Tarayıcı sitesi ziyaret eder (kullanıcı tarafından veya AI agent tarafından).
3. [] Network trafiği HAR dosyasına kaydedilir.
4. [] Konfigüre edilmiş model trafiği okuyarak çalışan bir API client'ı yazar.

**Prompt/kod/ayar:** Website URL + hedef veriler (örn. 'fetch all Apple jobs')
**Sonuç:** Çalışan bir API client'ı (Python, JavaScript, TypeScript, Go, Java, C#, PHP, Ruby, C veya PowerShell).
**Bizde (öneri, modelden):** Kurulu araçlarla nasıl bir API client'ı oluşturulur? Önce HAR dosyası kaydı yapılır, ardından AI agent trafiği analiz eder ve kod üretir.
**Daha iyi (öneri):** Hazır API'ler yerine doğrudan sitesi trafiğini analiz ederek daha güvenilir ve güncel bir API elde edilir.
