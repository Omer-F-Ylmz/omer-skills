# web-kod (DYkU-6VsOrm)

**Amaç:** Marka keşfi ve tasarım işlemlerini tek terminalde birleştirerek özel animasyonlu bir site oluşturmak.
**Araçlar:** Firecrawl, Claude Code, Nano Banana 2, GitHub, Vercel

**Adımlar**
1. [0:08-0:11] Firecrawl ile müşterinin sitesini taramak ve brand.json oluşturmak. Bu araç logoları, renkleri, fontları ve kopyaları otomatik olarak çeker.
2. [0:15-0:19] Claude Code'a girerek brand.json'u alarak görsellerin (hero, feature illustrasyonları, OG image, favicon) haritasını oluşturmak.
3. [0:22-0:27] Nano Banana 2'de üç pass ile temiz bir hero görsel ve patlatılmış versiyon oluşturmak, ardından bu görseli kısa bir geçiş videosuna dönüştürmek.
4. [0:28-0:31] Geçiş videosunu CloudCode'a yükleyerek web sitesi oluşturma workflow'u başlatmak. Branding, Layout ve Mobile ayarları hazır hale getirilir.
5. [0:36-0:39] Müşterinin mevcut HTML kodunu yapıştırarak entegre etmek. Bu adımda aynı yapıyı 10 kat daha iyi bir sonuç elde etmek için kullanılır.
6. [0:42-0:44] GitHub ve Vercel'i bağlayarak siteyi yayına almak. Böylece gerçek bir siteye ve URL'ye sahip olunur.

**Prompt/kod/ayar:** Firecrawl (brand.json oluşturma), Claude Code (Asset Prompt), Nano Banana 2 (görsel/geçiş video), CloudCode (site oluşturma), GitHub + Vercel (yayın).
**Sonuç:** Özel animasyonlu, marka uyumlu bir web sitesi oluşturulur.
**Bizde (öneri, modelden):** Kurulu araçlarla Firecrawl ve Claude Code kullanarak brand.json oluşturulabilir, ardından Nano Banana 2 ile görsel tasarımlar yapılarak CloudCode ile site oluşturulabilir. GitHub + Vercel entegrasyonu için kendi kurulum gerektirir.
**Daha iyi (öneri):** Kullanılan araçların API entegrasyonlarını optimize etmek, otomatik prompt oluşturma ve daha hızlı geçiş süreçleri sağlayabilir.
