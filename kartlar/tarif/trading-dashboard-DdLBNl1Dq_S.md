# trading-dashboard (DdLBNl1Dq_S)

**Amaç:** Bloomberg terminali alternatifi ücretsiz trading dashboard oluşturmak
**Araçlar:** Next.js, Express, TypeScript

**Adımlar**
1. [0:24] Repo'yu klonla
2. [0:24] npm install ile kurulum yap
3. [0:24] npm run dev ile çalıştır

**Prompt/kod/ayar:** npm install && npm run dev
**Sonuç:** Canlı trading terminali
**Bizde (öneri, modelden):** kurulu araçlarla nasıl
**Daha iyi (öneri):** Widget-based workspace (drag/resize)
