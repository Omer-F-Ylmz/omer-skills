# n8n-kurulum (DQwPHoljyij)

**Amaç:** Kendi özel otomasyon sunucusu kurmak.
**Araçlar:** Render (Free Plan), Docker, n8n Docker Image

**Adımlar**
1. [0:10-0:14] Render platformuna gidin ve ücretsiz bir hesap oluşturun.
2. [0:14-0:20] Render arayüzünde 'Deploy New Web Service' seçeneğine tıklayın.
3. [0:16-0:20] n8n'in Docker Image linkini Render'a yapıştırın ve 'Connect' butonuna tıklayın.
4. [0:20-0:23] Free Plan'ı seçin ve 'Create Web Service' butonuna tıklayın.
5. [0:23-0:26] Sunucu hazır olduğunda, n8n Owner Account setup yapın.

**Prompt/kod/ayar:** n8n Docker Image linki: https://hub.docker.com/r/n8nio/n8n (varsayılan olarak)
**Sonuç:** Kendi özel, aboneliksiz ve sınırsız otomasyon sunucusu hazır.
**Bizde (öneri, modelden):** Kurulu araçlarla n8n'in Docker Image'ini yerel olarak çalıştırabilir ve Render gibi bulut platformları kullanarak deploy edebilirsiniz.
**Daha iyi (öneri):** Yerel olarak çalıştırmak için Docker Desktop veya benzeri araçları kullanarak daha hızlı ve kontrolü artırabilirsiniz.
