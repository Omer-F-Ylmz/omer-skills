# prompt-hilesi (Ddrki7GugWV)

**Amaç:** Claude Code kullanıcılarına AI modelleri arasında geçiş yapabilme, hafıza yönetimi, bağlam optimizasyonu ve kod iyileştirmeyi sağlayan eklentiler sunmak.
**Araçlar:** OmniRoute (API geçişi ve limit yönetimi), Claude-Mem (oturumlar arası hafıza), Headroom (bağlam sıkıştırma), Claude Code Setup Plugin (kod analizi ve öneriler), TaskObserver (meta-yetenek geliştirme)

**Adımlar**
1. [0:00-0:02] Kullanıcıya 'şeklenti kurmadan önce cloud kodu kullanmayın' uyarısı yapıldı.
2. [0:02-0:09] OmniRoute eklentisinin, 200+ AI sağlayıcıya API bağlantısı sağlayarak limit dolduğunda otomatik geçiş yapmasını anlattı.
3. [0:14-0:18] Claude-Mem eklentisinin, cloud'a oturumlar arası hafıza ekleyerek sürekli başlangıç gerektirmeyen bir çalışma akışı sağladığını açıkladı.
4. [0:22-0:26] Headroom eklentisinin, bağlamı sıkıştırarak token kullanımını %60-95 azalttığını gösterdi.
5. [0:29-0:34] Claude Code Setup Plugin'ın kod tabanını tarayıp uygun yetenekleri önerdiğini ve MCP sunucuları ile entegrasyon sağladığını anlattı.
6. [0:40-0:44] TaskObserver'ın kullanıcı çalışmasını izleyip arka planda yetenekleri geliştirmeyi sağladığını açıkladı.

**Prompt/kod/ayar:** Claude Code eklentileri için API geçişi, hafıza yönetimi, bağlam optimizasyonu ve kod iyileştirmeyi destekleyen ayarlar.
**Sonuç:** Kullanıcıya 5 adet Claude Code eklentisi sunuldu ve her birinin amacı, kullanımı ve avantajları anlatıldı.
**Bizde (öneri, modelden):** Kurulu Claude Code eklentileriyle API geçişi ve bağlam yönetimi için OmniRoute ve Headroom'ı kullanarak token tüketimini azaltabiliriz.
**Daha iyi (öneri):** Eklentilerin entegrasyonunu otomatikleştirmek ve kullanıcı deneyimini iyileştirmek için TaskObserver'ın meta-yetenek geliştirme özelliğini kullanabiliriz.
