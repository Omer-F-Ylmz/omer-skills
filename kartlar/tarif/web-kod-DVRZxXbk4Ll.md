# web-kod (DVRZxXbk4Ll)

**Amaç:** Tek bir prompt ile 3D, katmanlı ve etkileşimli web siteleri oluşturmak.
**Araçlar:** AI kod üreteç (Gemini AI), Prompt temelli görsel üreteç, 3D animasyon tarifi, Scroll-driven 3D arka plan animasyonu

**Adımlar**
1. [0:25-0:30] Websitesinin konusunu tanımlayan prompt yaz. Örnek: 'futuristic AI agency'.
2. [0:39-0:42] Görsel stilini seç ve AI tarafından görseller üretsin.
3. [0:45-0:50] İstediğiniz hareket tarifi yaz veya otomatik animasyon seçeneğini kullan.
4. [0006:06-0006:09] Arka plan vibesını tanımlayan prompt yaz ve 3D arka plan animasyonunu oluştur.
5. [0009:06-0009:09] AI tarafından kod üretilmesini bekle ve hazır web sitesini indir.

**Prompt/kod/ayar:** Gemini AI generating code...
**Sonuç:** Fully-structured, 3D immersive website layout
**Bizde (öneri, modelden):** Kurulu araçlarla nasıl prompt temelli 3D web sitesi oluşturulur: AI kod üreteçleri ve görsel üreteçleri kullanarak.
**Daha iyi (öneri):** Kullanıcıların kendi animasyon ve görsel tariflerini ekleyebilmesi için daha fazla özelleştirme seçenekleri eklemek.
