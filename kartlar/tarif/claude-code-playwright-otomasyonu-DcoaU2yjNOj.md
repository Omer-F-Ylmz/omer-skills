# claude-code-playwright-otomasyonu (DcoaU2yjNOj)

**Amaç:** Claude Code ile Playwright kullanarak otomatik test süreçli web sitesi oluşturmak.
**Araçlar:** Claude Code, Playwright CLI, Visual Studio Code

**Adımlar**
1. [] Playwright kurulumunu tamamlayın ve kuralları CLAUDE.md dosyasına ekleyin.
2. [] Claude Code'a hedef web projesi için detaylı prompt verin.
3. [] Claude'un formu oluşturmasını, test etmesini ve hataları otomatik düzeltmesini izleyin.

**Prompt/kod/ayar:** CLAUDE.md
**Sonuç:** Otomatik olarak oluşturulmuş, kendi hatalarını test edip düzelten çalışan bir web formu.
**Bizde (öneri, modelden):** kurulu araçlarla nasıl
**Daha iyi (öneri):** MCP sunucuları yerine Playwright CLI kullanmak token tasarrufu sağlar.
