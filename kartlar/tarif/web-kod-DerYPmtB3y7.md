# web-kod (DerYPmtB3y7)

**Amaç:** Interaktif 3D bileşenleri web sayfasına entegre etme.
**Araçlar:** @designcodeio/threeui, Three.js, CSS

**Adımlar**
1. [] Three.js bileşenlerini ThreeUI kütüphanesi aracılığıyla ekrana yüklemek için `import` komutlarını kullan.
2. [] Bileşenleri Scene fonksiyonu içinde oluşturmak için `export function Scene()` yapısını kullan.
3. [] Örnek kodda `wovenCloth` bileşenini kullanarak 3D dokuma etkisi oluşturulur.

**Prompt/kod/ayar:** threeui.com üzerinden interaktif 3D bileşenleri keşfetmek için `Copy Prompt` düğmesi kullanılır.
**Sonuç:** Interaktif 3D bileşenlerin web sayfasına entegre edilmesi ve kullanıcı etkileşimi sağlanması.
**Bizde (öneri, modelden):** Kurulu Three.js araçlarıyla `threeui` kütüphanesini entegre ederek benzer bileşenler oluşturmak için `npm install @designcodeio/threeui` komutu kullanılır.
**Daha iyi (öneri):** Kendi bileşenlerinizi oluşturmak için Three.js API'sini derinlemesine kullanarak daha özelleştirilmiş etkiler elde edilebilir.
