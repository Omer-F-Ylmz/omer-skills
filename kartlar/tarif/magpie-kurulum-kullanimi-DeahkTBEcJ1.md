# magpie-kurulum-kullanimi (DeahkTBEcJ1)

**Amaç:** Claude Code hız limitlerini aşmak ve farklı modelleri entegre etmek.
**Araçlar:** Magpie, Claude Code, DeepSeek, Kimi, GLM

**Adımlar**
1. [açıklama] Local gateway'i çalıştırın.
2. [açıklama] Sağlayıcıları (DeepSeek, Kimi vb.) ekleyin.
3. [0:07] Komutu çalıştırarak geçiş yapın.
4. [0:10] Hesapları bir gruba ekleyerek limit dolduğunda otomatik geçişi sağlayın.

**Prompt/kod/ayar:** magpie claude deepseek/deepseek-v4-pro, magpie accounts discovery off, DO_NOT_TRAC
**Sonuç:** Kesintisiz çalışma ve model esnekliği.
**Bizde (öneri, modelden):** Yerel gateway üzerinde model yönlendirme.
**Daha iyi (öneri):** Hesap gruplandırma ile limit takılmalarını engelleme.
