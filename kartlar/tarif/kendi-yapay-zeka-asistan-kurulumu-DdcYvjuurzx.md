# kendi-yapay-zeka-asistan-kurulumu (DdcYvjuurzx)

**Amaç:** Kişisel bir AI asistanını ücretsiz olarak kurmak ve kullanıcıya günlük özet/iş takibi sağlamak.
**Araçlar:** GitHub proje bağlantısı, Claude Code (Cloud Code), ElevenLabs (ses entegrasyonu), Takvim, mailler, finans gibi entegre edilebilecek araçlar

**Adımlar**
1. [0:07-0:10] GitHub proje bağlantısını kopyalayın ve Cloud Code'a yapıştırın. ‘Bunu bilgisayarıma kur’ komutunu verin.
2. [0:10-0:13] Cloud Code tarafından otomatik kurulum işlemini bekleyin. Projeyi indirip gerekli ayarlamaları yapın.
3. [0:18-0:20] ElevenLabs'dan ses anahtarını alın ve tercih ettiğiniz sesi seçin.
4. [0:20-0:24] Seçilen sesi Cloud Code'a entegre etmeyi talimat verin.
5. [0:24-0:29] Kullandığınız takvim, mailler ve finans gibi araçları asistanla bağlayın.
6. [0:29-0:33] Asistanın günlük özet ve iş takibi için kullanımını başlatın.

**Prompt/kod/ayar:** GitHub proje linki + 'bunu bilgisayarıma kur' komutu (Claude Code)
**Sonuç:** Kişisel AI asistanı kuruldu ve takvim, mailler, finans gibi araçlar entegre edildi. Sürekli özet ve iş takibi sağlandı.
**Bizde (öneri, modelden):** Kurulu araçlarla (GitHub, Claude Code, ElevenLabs) benzer bir yapay zeka asistanı kurmak için: 1) GitHub projesini indirin, 2) Claude Code ile otomatik kurulumu başlatın, 3) ElevenLabs ses entegrasyonunu yapın, 4) Kullandığınız araçları bağlayın.
**Daha iyi (öneri):** Kullanıcıya daha fazla özelleştirme seçenekleri sunmak (örn. ses tonu, dil desteği, entegre edilebilecek araç sayısı).
