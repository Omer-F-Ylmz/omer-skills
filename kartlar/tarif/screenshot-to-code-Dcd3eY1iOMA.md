# screenshot-to-code (Dcd3eY1iOMA)

**Amaç:** Ekran görüntülerini veya tasarımları kodlamak için AI tabanlı bir araç kullanarak web sitesi kodlarını hızlıca oluşturmak.
**Araçlar:** GitHub repo (screenshot-to-code), Al (AI) modeli, Çevresel değişkenler (NEXUS_API_KEY, REPLICATE_API_KEY, ANTHROPIC_API_KEY), Ekran görüntüleri

**Adımlar**
1. [0:09-0:16] GitHub reposunu klonla ve çevresel değişkenleri ayarla.
2. [0:16-0:18] Klonlanacak web sitesinin ekran görüntülerini hazırla.
3. [0:18-0:22] Kodu oluşturma komutunu çalıştır.
4. [0:26-0:31] Üretilen kodun doğruluğunu ve tasarım uyumunu kontrol et.

**Prompt/kod/ayar:** screenshot-to-code repo'su kullanılarak ekran görüntülerini kodlamak için AI modeli (NEXUS, REPLICATE, ANTHROPIC) ile entegrasyon.
**Sonuç:** Crunchyroll web sitesinin logo ve kapak sanatını doğru şekilde kodladığı gözlemlendi.
**Bizde (öneri, modelden):** kurulu araçlarla ekran görüntülerini kodlamak için screenshot-to-code gibi bir araç kullanarak AI tabanlı kod oluşturma işlemini gerçekleştirmek.
**Daha iyi (öneri):** Ekran görüntülerinin daha yüksek çözünürlükte alınması ve AI modelinin daha gelişmiş yapılandırılmasıyla daha doğru sonuçlar elde edilebilir.
