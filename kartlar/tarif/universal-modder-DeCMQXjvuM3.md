# universal-modder (DeCMQXjvuM3)

**Amaç:** Yapay zeka ajanlarına oyun modlama yeteneği kazandırmak
**Araçlar:** decompile araçları, Reshade, yerel köprüleme teknolojisi, klavye/fare simülasyonu

**Adımlar**
1. [0:00-0:25] Oyunun motorunu decompile edip kaynak kodunu çıkartma
2. [0:25-0:30] 3D modelleri ve silah çizimlerini renderlama
3. [0:30-0:36] Modun test edilmesi için oyun arka planda çalıştırma ve girdi simülasyonu
4. [0:36-0:44] İki oyun motorunu tek sahnede birleştirme (Reshade + yerel köprü)

**Prompt/kod/ayar:** GitHub: rehan-remade/universal-modder
**Sonuç:** GTA 5 + Minecraft Java motorunu aynı sahnede çalıştıran mod
