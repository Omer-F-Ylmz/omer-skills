# flowsint-kurulum (DdSwfSNgFiJ)

**Amaç:** OsINT grafik araştırma aracını yerel makinada çalıştırmak
**Araçlar:** git, Docker, TypeScript, Node.js

**Adımlar**
1. [0036-0039] Önkoşulları kur: Docker ve Node.js gibi gereksinimleri sağla
2. [0038-0042] Projeyi klonla ve dizine gir
3. [0038-0039] Projeyi çalıştır: `make prod` komutu
4. [0040-0042] Windows kullanıcıları için: Command Prompt/PowerShell ile projeyi çalıştır

**Prompt/kod/ayar:** git clone https://github.com/reconurge/flowsint.git && cd flowsint && make prod
**Sonuç:** Araştırma için otomatik bağlantılar oluşturan grafik arayüzü başlatılır
**Bizde (öneri, modelden):** kurulu Docker ve Node.js ile `make prod` komutu çalıştırarak yerel grafik araştırma aracını başlatabilirsiniz
**Daha iyi (öneri):** Docker kullanarak daha kolay ve izole bir ortamda çalıştırma
