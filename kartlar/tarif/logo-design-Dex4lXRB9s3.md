# logo-design (Dex4lXRB9s3)

**Amaç:** Referans logosuyla karşılaştırarak profesyonel SVG logo tasarımı yapmak.
**Araçlar:** 1,400+ referans logo kütüphanesi, Agent Skills (Gemini CLI, CodexCLI, Cursor, GitHub Copilot), Pythondan bağımsız kod, Marka prensipleri ve sunum araçları

**Adımlar**
1. [] Referans logosunu inceleme ve marka türü, teknik, geometri, ruh ve endüstriye göre sınıflandırma.
2. [] Brief oluşturma, kelime haritalama, uygun marka tipini seçme.
3. [] Konsept geliştirme, geometrik yapı oluşturma, optik düzeltmeler, renk, tipografi, lockup testleri.
4. [] Sunum panoları oluşturma, favicon/app-icon/web-manifest ihraç etme.

**Prompt/kod/ayar:** Dependency-free Python, Agent Skills (Gemini CLI, CodexCLI, Cursor, GitHub Copilot)
**Sonuç:** Profesyonel SVG logo tasarımı ve sunum hazırlama.
**Bizde (öneri, modelden):** Kurulu araçlarla nasıl: Referans logosunu OCR ile okutup, AI modelleri kullanarak tasarım aşamalarını otomatikleştirme.
**Daha iyi (öneri):** Kullanıcı geri bildirimleriyle sürekli iyileştirme, daha geniş referans kütüphanesi entegrasyonu.
