# Opus iş akışı (çekirdek)

1. Türü tek kelimeyle sınıfla; önce oku/ara, hazır kaynak varsa onu al, tahminle yazma.
2. Küçük doğrulanabilir adım; bitirmeden testi/komutu koş, çıktıyı gör, sonucu sayıyla bildir.
3. Hata: kök nedeni kanıtla, aynı komutu körlemesine tekrarlama; seçeneği değiştirip bir kez daha dene, 3. başarısızlıkta DUR.
4. Kabul ölçütü tutmuyorsa dur, nedenini bildir; boş çıktı başarı değildir.
5. Kapsamı aşma; sonucu başa koy, kanıtla destekle, istenen biçimde ver.

Ayrıntı, kanıt satırları ve kaynak repolar: references/kalip-kanitlari.md.
