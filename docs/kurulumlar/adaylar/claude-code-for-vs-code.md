## Ne
Anthropic'in resmi VS Code eklentisi. Claude Code'u editörün içinde yan panelde açar. Bu oturumda web araması ya da sayfa getirme yapılmadı. Aşağıdaki bilgiler videodan ve genel bilgiden geliyor.
## Mekanizma
Eklenti, Claude Code'u VS Code içine bağlar ve sağ panelde bir sohbet arayüzü gösterir. Ayrıntılar (dosya diff'i gösterme, seçili kodu bağlam olarak gönderme, CLI ile ilişkisi) bu oturumda doğrulanmadı, bu yüzden bilinmiyor. Videoda yalnızca panelin açılması görüldü.

## Kurulum
- VS Code'da Extensions (Ctrl+Shift+X) sekmesini aç
- 'Claude Code for VS Code' (yayıncı: Anthropic) eklentisini ara ve Install'a bas
- Eklentiyi aç ve Anthropic hesabıyla ya da API anahtarıyla giriş yap (yöntem doğrulanmadı)
