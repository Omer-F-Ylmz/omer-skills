# before.click


- **Ne sunuyor**
  App Store ekran görüntüleri, onboarding, paywall ve icon tasarımları içeren **iOS/Mac uygulama tasarım ilham galerisi** (ASO ve UI/UX referansları).

- **Ücretsiz kısım**
  - **Örnek görüntüler** (405+ ekran, 14 paywall, 405 icon)
  - **Kategorilere ayrılmış koleksiyonlar** (Productivity, Health, Travel vs.)
  - **Haftalık e-posta güncellemeleri** (yeni ekranlar/paywall/onboarding örnekleri)

- **İndirilebilir kaynak/kod**
  - **Özel "skills" paketi** (`npx skills add alexszczczurek/before-skills`) → ASO yetenekleri ekleme.

- **Teknoloji**
  - **Next.js** (site yapısı: `_next` dosyaları)
  - **Frontend**: React (GSAP, Tailwind, Framer gibi teknolojiler **yok**).

- **Bizde kullanım**
  - **Skill/ASO uzmanları** için **iOS/Mac uygulama tasarım referansları** (öncelikle App Store Optimizasyonu).
  - **UI/UX tasarımcılar** için **onboarding/paywall örnekleri**.
