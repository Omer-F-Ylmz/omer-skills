# shadcnblocks.com

**Sonuç:**

*   **Ne Sunuyor:** Shadcn UI ve Tailwind tabanlı, 2478 blok, 2154 bileşen ve 21 şablon seti (dashboard, hero, bento, vb.).
*   **Ücretsiz Kısım:** Blokların bir kısmı "Browse Blocks" ile erişilebilir; ancak premium erişim ve tam şablonlar ücretlidir.
*   **İndirilebilir Varlık/Kaynak Kod:** Copy-paste destekli bileşenler; Shadcn CLI ile kurulum veya doğrudan blok/şablon satın alımı.
*   **Teknoloji:** Shadcn/UI, Tailwind CSS, React, Next.js, Astro.
*   **Bizde Kullanım:** Landing page, dashboard arayüzleri ve marketing sayfalarının hızlı prototiplenmesi ile responsive UI geliştirme süreçlerinde kullanılır.
