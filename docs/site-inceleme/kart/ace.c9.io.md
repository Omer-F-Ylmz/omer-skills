# ace.c9.io


- **Ne sunuyor**
  - JavaScript tabanlı, yüksek performanslı **kod editörü** (45 dil, 24 tema).
  - Web uygulamalarına **entegre edilebilir** (embedable).
  - Cloud9 IDE'nin ana editörü; **Mozilla Skywriter (Bespin)**'in halefi.
  - **Sublime/Vim** seviyesinde özellikler (sentezleme, arama, düzenleme).

- **Ücretsiz kısım**
  - Tamamen **açık kaynak** (MIT lisansı). ⚠[kanitsiz]
  - **Geliştirme ve entegrasyon** ücretsiz. ⚠[kanitsiz]

- **İndirilebilir kaynak/kod**
  - GitHub: [ace](https://github.com/ajaxorg/ace) (ana repo).
  - Ekstansiyonlar: [linters](https://github.com/mkslanc/ace-linters), [collab](https://github.com/convergencelabs/ace-collab-ext).

- **Teknoloji**
  - **JavaScript** (browser-based).
  - **Sentezleme** (TextMate/Sublime formatları destekliyor).
  - **API** ve **kullanıcı rehberleri** mevcut.

- **Bizde kullanım**
  - **Frontend/Backend** geliştiriciler için **kod editörü entegrasyonu**.
  - **Öğretim/öğrenme** araçları (örn. kod denemeleri).
  - **Web IDE** veya **editörlü formlar** için.
