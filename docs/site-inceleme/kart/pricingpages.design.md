# pricingpages.design


- **Ne sunuyor**: Fiyatlandırma sayfaları tasarım örneklerini küratörlü bir galerisi (ilham kaynağı).
- **Ücretsiz kısım**: Tüm örnekler ücretsiz görüntülenebilir; detaylı filtreleme ve kategorilendirme.
- **İndirilebilir kaynak**: **Yok** (kod/PSD gibi).
- **Teknoloji**:
  - **GSAP** (animasyon)
  - **Webflow** (site yapısı)
  - **Fathom** (izleme)
  - **Cloudflare Turnstile** (bot koruma)
- **Bizde kullanım**: **Frontend/UX tasarımcılar** için fiyatlandırma sayfaları tasarım ilhamı.
