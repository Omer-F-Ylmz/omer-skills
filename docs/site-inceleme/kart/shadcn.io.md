# shadcn.io

**Sonuç:** shadcn.io teknik site kartı aşağıdadır.

*   **Ne sunuyor:** React, Vue, Svelte ve Solid projeleri için 6.181 blok, 14 şablon ve 174 bileşenden oluşan, responsive ve erişilebilir UI kütüphanesi.
*   **Ücretsiz kısım:** Blokların, ikonların ve bileşenlerin büyük çoğunluğuna göz atma ve erişim imkanı.
*   **İndirilebilir varlık/kaynak kod:** Komut istemi (prompt) ile doğrudan projeye kurulum (AI agent entegrasyonu ile); hazır şablonlar.
*   **Teknoloji:** Shadcn/ui tabanlı, Next.js ve Tailwind CSS uyumlu yapı.
*   **Bizde kullanım:** Hızlı arayüz prototipleme ve kurumsal ölçekte standart bileşen sistemleri geliştirme.
