# scrollhaus.ai

**Sonuç:**

*   **Ne sunuyor:** 100+ animasyonlu web şablonu, UI bileşenleri, 3D figürler, arka plan efektleri ve konsept örnekleri.
*   **Ücretsiz kısım:** GitHub üzerinde sınırlı sayıda ücretsiz şablon ve kaynak kod erişimi (scrollhaus-free).
*   **İndirilebilir varlık/kaynak kod:** GitHub üzerinden indirilebilir kaynak kod mevcuttur; site içi şablonlar genellikle ücretli planlar (yıllık/aylık) kapsamındadır.
*   **Teknoloji:** React tabanlıdır.
*   **Bizde kullanım:** Web projelerinde hareketli prototipler, UI ilhamı ve hazır animasyonlu bileşenleri hızla entegre etmek için kullanılır.
