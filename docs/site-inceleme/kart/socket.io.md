# socket.io


- **Ne sunuyor**: WebSocket tabanlı, çift yönlü ve düşük gecikmeli platformlararası iletişim kutuphanesi.
- **Ücretsiz kısım**: Tam dokümantasyon, örnekler, API'ler (Server/Client), GitHub projeleri, CDN desteği.
- **İndirilebilir kaynak kod**: GitHub'da açık kaynak (MIT lisansı).
- **Teknoloji**: Node.js, Bun, React, Vue, Next.js gibi çerçevelerle entegre.
- **Bizde kullanım**: **Backend/Real-time iletişim** (chat, oyun, live güncelleme) için **Socket.IO** kullanılır.
