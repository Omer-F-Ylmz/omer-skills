# pptr.dev


- **Ne sunuyor**
  Chrome/Firefox'u DevTools Protokolü veya WebDriver BiDi üzerinden kontrol eden **JavaScript kütüphanesi** (headless modda çalışır).
  - Otomatik tarama, test, render, animasyon kontrolü sağlar.
  - **Puppeteer API** ve **@puppeteer/browsers** ile entegre Chrome/Firefox sürümleri indirilir.

- **Ücretsiz kısım**
  Tamamen **açık kaynak** (MIT lisansı), ücretsiz kullanım ve geliştirme desteği.

- **İndirilebilir kaynak/kod**
  - GitHub: [Puppeteer](https://github.com/puppeteer/puppeteer) (API, CI/CD, RFC'ler)
  - **Kütüphane**: `npm i puppeteer` (Chrome/Firefox entegrasyonu içeren paket)
  - **Core**: `npm i puppeteer-core` (sadece kütüphane, Chrome indirmez)

- **Teknoloji**
  - **DevTools Protokolü** (Chrome/Firefox) + **WebDriver BiDi** destekli.
  - **Headless** çalışma modu (UI'siz).
  - **Node.js** için yazılmış, **JavaScript/TypeScript** ile kullanılır.

- **Bizde kullanım (hangi skill/is için)**
  - **Frontend Test Otomasyonu**: UI testleri (Cypress/Puppeteer entegrasyonu).
  - **Web Scraping**: Dinamik içerik (SPA) işleme.
  - **Animasyon/Interaktif Kontrol**: Framer Motion, GSAP gibi kütüphanelerle beraber.
  - **DevOps/QA**: CI/CD'da tarama testleri (GitHub Actions entegrasyonu).
  - **Skill**: **JavaScript/TypeScript**, **Node.js**, **DevTools Protokolü**, **Automation**.
