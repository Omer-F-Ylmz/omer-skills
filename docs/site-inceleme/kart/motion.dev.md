# motion.dev


- **Ne sunuyor**: React, Vue ve JavaScript için **hardware-accelerated** animasyon çözümü (layout, scroll, gesture, 3D, fiziksel spring animasyonları).
- **Ücretsiz kısım**: **Özgür ve açık kaynak** (npm: `npm install motion`), örnekler, dokümantasyon.
- **İndirilebilir kaynak**: GitHub: [motiondivision/motion](https://github.com/motiondivision/motion).
- **Teknoloji**: Performanslı animasyon API’ları (küçük kod, ekspresif UI).
- **Bizde kullanım**: **Frontend animasyonlar** (React/Vue/JS), **interaktif UI** geliştirme (gesture, scroll, 3D).
