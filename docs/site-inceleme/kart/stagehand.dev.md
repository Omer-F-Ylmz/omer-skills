# stagehand.dev

**Sonuç:** Kanıt verilerine dayalı teknik site kartı aşağıdadır.

* **Ne sunuyor:** Browser agentleri için SDK; Playwright benzeri API'ler (goto, click, locator, screenshot), self-healing (kendi kendini onaran) işlemler ve doğal dil ile Act, Observe, Extract komutları.
* **Ücretsiz kısım:** Kanıtta fiyat bilgisi bulunmamaktadır.
* **İndirilebilir varlık / kaynak kod:** GitHub üzerinde açık kaynak kod deposu (`https://github.com/browserbase/stagehand`) sunulmaktadır; doğrudan dosya indirme bağlantısı kanıtta yoktur.
* **Teknoloji:** TypeScript, Python ve Go desteği; Next.js altyapısı.
* **Bizde kullanım:** Yapay zeka tabanlı web otomasyonu, tarayıcı tabanlı ajan görevleri ve test otomasyon süreçleri için skill/iş amaçlı kullanılabilir.
