# docs.polyhaven.com


- **Ne sunuyor**
  Poly Haven varlıklarının (HDRIs, tekstürler, modeller) kullanımını ve üretimini anlatan teknik belgeler, standartlar ve kullanıcı kılavuzları.

- **Ücretsiz kısım**
  Tüm içerik **CC-BY lisansı** ile ücretsiz erişimli; wiki düzenleme desteği Discord üzerinden.

- **İndirilebilir kaynak/kod**
  Varlık örnekleri (HDRIs, modeller) indirilebilir; **kaynak kod** yok (Wiki.js platformu kullanılıyor).

- **Teknoloji**
  **React** tabanlı Wiki.js ile çalışan, Cloudflare Insights ile izlenen dinamik dokümantasyon.

- **Bizde kullanım**
  **3D modelleme** (Blender Add-on), **fotoğrafçılık** (HDRI kullanımı), **sanat üretimi** (tekstür/prop oluşturma) için teknik referans.
