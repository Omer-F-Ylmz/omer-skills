# swarms.xyz


- **Ne sunuyor**
  Multi-agent AI sistemleri için **kurulum, deploy, yönetim ve monetizasyon** altyapısı.
  - **Kapsam**: Agent mimarileri, iletişim protokolleri, performanslı runtime, bellek yönetimi, simülasyon ortamları.
  - **Hedef**: Üretim düzeyinde otonom sistemler için **performanslı, güvenilir ve ölçeklenebilir** çözümler.

- **Ücretsiz kısım**
  - **Dökümantasyon** (Blog, Academy, Docs).
  - **Geliştirici araçları** (Python/Rust SDK’ları, GitHub reposu).
  - **Test ortamları** (API, Cloud, Marketplace).

- **İndirilebilir kaynak/kod**
  - [GitHub Reposu](https://github.com/kyegomez/swarms) (Python)
  - [GitHub Reposu](https://github.com/The-Swarm-Corporation/swarms-rs) (Rust)
  - **Paket yöneticileri**: `pip install swarms` / `cargo add swarms-rs`.

- **Teknoloji**
  - **Bağımlılıklar**: `three.js` (animasyon/3D destekli). ⚠[kanitsiz]
  - **Çerçeve**: Next.js (arka plan scriptleri `_next` ile işaretleniyor). ⚠[kanitsiz]
  - **Özel**: Multi-agent iletişim protokolleri, performanslı runtime, simülasyon ortamları. ⚠[kanitsiz]

- **Bizde kullanım**
  - **Skill**: AI agent mimarisi, performans optimizasyonu, otomasyon sistemleri.
  - **İş**: **Multi-agent AI geliştirme**, otonom sistemler, finansal/enterprise otomasyonlar.
  - **Örnek**: Fortune 500 firmaları, 2B+ agent oluşturulmuş.
