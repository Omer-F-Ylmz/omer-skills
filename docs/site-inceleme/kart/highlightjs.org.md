# highlightjs.org


- **Ne sunuyor**
  JavaScript kod syntax vurgulama ve renklendirme kütüphanesi (193 dil, 516 tema, otomatik dil tespiti, bağımsız çalışma).

- **Ücretsiz kısım**
  CDN, npm (`npm install highlight.js`), GitHub kaynak kodu, demo, dokümantasyon ve kullanım örnekleri ücretsiz.

- **İndirilebilir kaynak/kod**
  [Download](https://highlightjs.org/download) (bundle), npm (`highlight.js`), GitHub repo (`highlightjs/highlight.js`).

- **Teknoloji**
  **Framework uyumluluğu**: React, Next.js (kanıtlı). **Bağımsız**: Zero dependency, Node.js/Deno destekli.
  **Kullanım**: CDN, ES6 modül, Vue plugin, web worker, npm paketi.

- **Bizde kullanım**
  **Skill**: Frontend (JS/React/Next), backend (Node.js), kod editörleri, dokümantasyon sayfaları.
  **İş**: Kod vurgulamalı loglar, API dokümantasyonu, eğitim materyalleri, teknik blog yazıları.
