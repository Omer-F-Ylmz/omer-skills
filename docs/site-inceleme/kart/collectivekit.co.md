# collectivekit.co

* **Ne sunuyor:** Figma UI Kit ve Tasarım Sistemi (Açık/Koyu mod, WCAG uyumlu renkler ve global tasarım tokenleri).
* **Ücretsiz kısım:** Kanıtta belirtilmemiş (Ücretli/Pricing var).
* **İndirilebilir varlık/kaynak kod:** Kanıtta doğrudan indirilebilir dosya veya GitHub bağlantısı yok (Framer şablonu satılıyor).
* **Teknoloji:** Framer (`events.framer.com`, `framerusercontent.com`).
* **Bizde kullanım:** UI/UX tasarım sistemleri, prototipleme ve hızlı arayüz standardizasyonu için.
