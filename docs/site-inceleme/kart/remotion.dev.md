# remotion.dev


- **Remotion** (Component/Animasyon Kütüphanesi)
  - **Ne sunuyor**: Kod tabanlı video ve motion graphics oluşturma; React ile programatik video yapımı, render ve animasyon işlemleri.
  - **Ücretsiz kısım**: Örnek projeler, dokümantasyon, temel özellikler (kısıtlı kullanım).
  - **İndirilebilir kaynak**: [Brand Assets](https://remotion.media/remotion-brand-assets.zip) (logo, örnekler).
  - **Teknoloji**: React tabanlı; Next.js, TypeScript desteği (Three.js, GSAP, Framer gibi alternatifler yok).
  - **Bizde kullanım**: Frontend/Backend geliştiriciler için video otomasyonu, motion design sistemleri, interaktif demo/editor yapımı.
