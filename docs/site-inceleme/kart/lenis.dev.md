# lenis.dev


- **Ne sunuyor**
  - WebGL/DOM senkronizasyonlu **smooth scroll** ve animasyon optimizasyonu.
  - **Tek satırda** entegrasyon (`new Lenis()`) veya Framer plugin ile no-code.
  - **Çapraz-device** uyumlu, ayarlanabilir scroll hissi (hız, ağırlık).
  - **Hijack** olmadan scrollbar kullanımı, aksesibilite koruma.

- **Ücretsiz kısım**
  - Kütüphane ve dokümantasyon **tamamen ücretsiz**.

- **İndirilebilir kaynak/kod**
  - GitHub: [lenis.dev](https://github.com/darkroomengineering/lenis) (MIT lisansı).

- **Teknoloji**
  - **Three.js** entegrasyonu destekli, **React/Vue/Next** bağımsız.

- **Bizde kullanım**
  - **Frontend** animasyon/performans optimizasyonu (WebGL, DOM senkronizasyon).
  - **Uygulama**: Smooth scroll, scroll-linked animasyonlar, immersive UI.
