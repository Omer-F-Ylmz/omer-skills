# cultofclaude.com


**Cult of Claude – Claude Code Kütüphanesi**

- **Ne sunuyor?**
  Claude Code için **36.6K+ skill** ve **20.1K+ agent** listesi (GitHub'dan toplanmış).
  Her birinin **kaynak kodu**, **komutları** ve **kullanım örnekleri** sunar.

- **Ücretsiz kısımlar**
  - Tüm listeleme **bedava** (browse/arama).
  - Skill/agent **kaynak kodları** doğrudan GitHub'dan linklenir.

- **İndirilebilir kaynak/kod**
  - **SKILL.md** dosyaları (prosedürler) ve **agent tanımları** (Markdown).
  - **Kullanım komutları** (örn: `claude skill install <repo>`).

- **Teknoloji**
  - **Kütüphane/komponent**: Claude Code uzantıları (skill/agent).
  - **Arka plan**: GitHub crawler (SKILL.md/agent dosyaları taraması).
  - **Kullanılan tech**: Astro (site), Cloudflare (CDN).

- **Bizde kullanım**
  - **Skill/agent geliştiricileri** için **marketplace** (kalite filtreli).
  - **Claude Code kullanıcıları** için **uzmanlık arama** (örn: PR review, migration).
  - **Örnek skilller**: Test otomasyonu, kod yazma yardımcıları.


*(Kanıt: Site metni, GitHub crawler işlevi, ücretsiz listeleme, Astro kullanımı.)*
