# n8n-skills.com


- **Ne sunuyor**
  - n8n için ücretsiz **Agent Skills paketi** (14 skill + router).
  - **n8n-mcp entegrasyonu** (OAuth ile host edilmiş).
  - **Agent Plugin 1.0** (Codex, Copilot, Gemini gibi araçlarla çalışır).
  - **Yapılandırılmış workflow** (webhook, Slack, Slack flow gibi).

- **Ücretsiz kısım**
  - MIT lisansı ile açık kaynak.
  - `npx skills add czlonkowski/n8n-skills` ile kolay kurulum.

- **İndirilebilir kaynak/kod**
  - GitHub: [n8n-skills](https://github.com/czlonkowski/n8n-skills) (plugin.json, 14 skill).
  - [n8n-mcp](https://github.com/czlonkowski/n8n-mcp) entegrasyonu.

- **Teknoloji**
  - **Agent Skills formatı** (Codex, Copilot, Gemini gibi araçlarla uyumlu).
  - **OAuth** ile host edilmiş n8n-mcp entegrasyonu.

- **Bizde kullanım**
  - **n8n Agent Plugin** geliştirme (AI agentleri için skill paketi).
  - **n8n-mcp** entegrasyonu (hosted n8n ile OAuth).
  - **n8n workflow** otomasyonu (Slack, webhook gibi).
