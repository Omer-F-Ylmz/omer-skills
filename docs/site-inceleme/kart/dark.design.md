# dark.design

- **Ne sunuyor:** Koyu temalı web sitesi tasarımları için seçilmiş ilham kaynağı galerisi.
- **Ücretsiz kısım:** Siteye erişim ve listelenen içerikleri inceleme.
- **İndirilebilir varlık/kaynak kod:** Kanıt metninde indirilebilir varlık veya kaynak kod bulunmuyor (yapılmadı: kanıtta yok).
- **Teknoloji:** Next.js altyapısı (`_next` betikleri).
- **Bizde kullanım:** Web tasarımı projelerinde koyu tema (dark mode) estetiği ve UI/UX ilhamı toplamak için ilham/referans skilli için.
