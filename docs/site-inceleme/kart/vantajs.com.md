# vantajs.com


- **Ne sunuyor**: Web sitelerine **özel animasyonlu 3D arka planlar** (kuşlar, bulutlar, dalgalar vs.) eklemeyi sağlayan **component/animasyon kütüphanesi**.
- **Ücretsiz kısım**: Tamamen ücretsiz, **CDN üzerinden kolayca entegre edilebilir** (min. 120KB).
- **İndirilebilir kaynak**: GitHub'da [kaynak kod](https://github.com/tengbao/vanta) mevcut.
- **Teknoloji**: **Three.js** tabanlı (WebGL), **60fps+ performans**, **mouse/touch interaktif**.
- **Bizde kullanım**: **Frontend/JS** (React/Next/Vue dışı) için **3D animasyon efektleri** (örn. portfolio, landing page).
