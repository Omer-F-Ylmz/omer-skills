# reactbits.dev


- **Ne sunuyor**
  217+ animasyonlu React bileşeni (arka planlar, UI efektleri, mikro bileşenler) ve **Center Stage** gibi 5 ücretsiz araç. Özel ayarlar veya ajansa devredilebilir.

- **Ücretsiz kısım**
  Tüm bileşenler ve araçlar **MIT lisansı** ile ücretsiz. GitHub'da kod ve örnekler mevcut.

- **İndirilebilir kaynak/kod**
  [GitHub](https://github.com/DavidHDev/react-bits) (MIT lisansı). `npx shadcn@latest add @react-bits/GradientWaves-TS-TW` ile kolayca entegre.

- **Teknoloji**
  React (Next.js destekli değil), GSAP, Three.js (destekli). Tailwind/TypeScript uyumlu bileşenler.

- **Bizde kullanım**
  **Frontend** (UI/UX), **animasyon** (web siteleri, reklamlar), **agency** (hızlı prototiplendirme) için ideal.
