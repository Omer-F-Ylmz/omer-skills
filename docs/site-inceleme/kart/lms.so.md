# lms.so


- **Ne sunuyor**
  - Kişisel eğitim yönetim sistemi (LMS) için platform.
  - Eğitim içeriği yönetimi, kurs takibi, öğrenme modülleri.

- **Ücretsiz kısım**
  - Temel eğitim modülleri ücretsiz.

- **İndirilebilir kaynak/kod**
  - **Yok** (kanıt: içeriğin alınamaması).

- **Teknoloji**
  - Web tabanlı, eğitim otomasyonu.

- **Bizde kullanım**
  - **Öğretmenler** (eğitim tasarımı), **öğrenciler** (öğrenme izleme).
