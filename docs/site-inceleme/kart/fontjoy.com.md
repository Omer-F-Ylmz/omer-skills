# fontjoy.com

Sonuç: **Fontjoy Teknik Kartı**

*   **Ne sunuyor:** Derin öğrenme tabanlı font eşleştirme ve görselleştirme aracı.
*   **Ücretsiz kısım:** Tüm font oluşturma ve eşleştirme araçları tamamen ücretsiz.
*   **İndirilebilir varlık/kaynak kod:** GitHub üzerinden kaynak koda erişim sağlanıyor; özel varlık indirme seçeneği bulunmuyor.
*   **Teknoloji:** `Three.js` kütüphanesi kullanılıyor; Google Analytics ve özel scriptler (`slider.js`, `main2.js`) ile çalışıyor.
*   **Bizde kullanım:** Arayüz (UI) tasarımı projelerinde tipografi ve font kombinasyonu oluşturma/test etme işleri için.
