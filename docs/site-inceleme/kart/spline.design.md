# spline.design


- **Ne sunuyor**
  3D tasarım, interaktif web deneyleri ve AI destekli 3D modelleme aracı. Kullanıcılar önceden hazır 3D tasarımları remixleyebilir veya doğrudan kontrol ile 3D oluşturabilir.

- **Ücretsiz kısım**
  Temel 3D tasarım ve interaktif deneyler ücretsiz. Özel özellikler premium planlarda.

- **İndirilebilir kaynak/kod**
  [İndirme](https://spline.design/download) ve [yedek](https://spline.design/download-mirror) linkleri mevcut.

- **Teknoloji**
  React + Next.js tabanlı, Three.js kütüphanesi kullanıyor.

- **Bizde kullanım**
  **Skill:** 3D tasarım, interaktif web, AI destekli üretim.
  **İş:** Branding, ürün tasarımı, gamified deneyler, 3D mockup/animasyon.
