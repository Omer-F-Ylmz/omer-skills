# shields.io

**Sonuç:**

*   **Ne sunuyor:** Proje metrikleri ve durumları için dinamik/statik "badge" oluşturma ve sunma hizmeti.
*   **Ücretsiz kısım:** Tamamı açık kaynak ve ücretsizdir.
*   **İndirilebilir varlık:** Docker imajı ve `badge-maker` NPM kütüphanesi.
*   **Teknoloji:** Docusaurus, NPM.
*   **Bizde kullanım:** GitHub projelerinin durumunu, versiyonlarını veya metriklerini görsel olarak dökümante etmek ve profesyonel görünüm sağlamak için kullanılacaktır.
