# originkit.dev

**Sonuç:**
* **Ne sunuyor:** Animasyonlu UI bileşenleri, 3D etkiler, interaktif galeriler ve arka plan animasyonları.
* **Ücretsiz kısım:** Temel keşif ve bileşen inceleme; fiyatlandırma sayfası mevcut.
* **İndirilebilir varlık / kaynak kod:** Kanıtta doğrudan dosya/indirme linki veya GitHub deposu belirtilmemiştir.
* **Teknoloji:** Next.js altyapısı (`_next`); harici kütüphane (React, Vue, Tailwind, GSAP vb.) tespiti kanıtta yoktur.
* **Bizde kullanım:** Arayüz geliştirme projelerinde dikkat çekici 3D efektler, interaktif galeriler ve arka plan animasyonları oluşturma skill'i için.
