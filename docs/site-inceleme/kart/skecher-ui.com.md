# skecher-ui.com


- **Ne sunuyor**
  React ve **shadcn CLI** ile kurulan **hareketli UI bileşenleri** kütüphanesi (38+ animasyonlu bileşen, canlı önyükleme ve kaynak kodu).

- **Ücretsiz kısım**
  Tüm bileşenler **açık kaynaklı**, ücretsiz kullanım ve özelleştirme imkanı sunar. ⚠[kanitsiz]

- **İndirilebilir kaynak/kod**
  GitHub: [skecher-ui](https://github.com/CoDesign-Spa27/skecher-ui) (CLI ile `npx shadcn@latest add CoDesign-Spa27/skecher-ui/apple-mail-tabs` ile entegre).

- **Teknoloji**
  **React** tabanlı, **Three.js** (3D animasyonlar) destekli. ⚠[kanitsiz]

- **Bizde kullanım**
  **Frontend geliştiriciler** için **animasyonlu UI bileşenleri** (mail tabs, brand animasyonları gibi) hızlı entegrasyonu sağlar.
