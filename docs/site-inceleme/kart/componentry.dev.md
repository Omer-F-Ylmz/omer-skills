# componentry.dev


- **Ne sunuyor**
  Canlı, düzenlenebilir **React animasyon bileşenleri** (hover, scroll, eye-tracking, partikül efektleri gibi) ve UI parçaları. Kodunu anında değiştirerek deneyimlenebilir. ⚠[kanitsiz]

- **Ücretsiz kısım**
  Tüm bileşenler ücretsiz, **MIT lisansı** ile paylaşılabilir. Örnekler: `magnetic-dock`, `cursor-driven-particle-typography`. ⚠[kanitsiz]

- **İndirilebilir kaynak/kod**
  GitHub: [https://github.com/harshjdhv/componentry](https://github.com/harshjdhv/componentry).
  **Shadcn CLI** veya AI editörleriyle entegre edilebilir (`npx shadcn@latest add @componentry/...`).

- **Teknoloji**
  **React** tabanlı (Next.js destekli değil). **GSAP**, **Three.js** gibi animasyon motorları kullanıyor. ⚠[kanitsiz]

- **Bizde kullanım**
  **Frontend/React geliştiricileri** için animasyonlu UI oluşturmak, **portfolio sayfaları**, **interaktif etkileşimler** (örn. mouse izleme, partikül efektleri).
