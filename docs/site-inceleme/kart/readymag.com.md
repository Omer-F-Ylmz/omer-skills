# readymag.com

- **Ne sunuyor:** Kod yazmadan sürükle-bırak yöntemiyle portföy, sunum ve açılış sayfaları tasarlama ve yayınlama aracı; Figma'dan içe aktarma ve özel imleç özellikleri barındırır.
- **Ücretsiz kısım:** Kanıt metninde açıkça belirtilmemiştir (fiyatlandırma sayfası mevcuttur).
- **İndirilebilir varlık/kaynak kod:** Kanıt verilerine göre indirilebilir varlık veya açık kaynak kod bulunmamaktadır.
- **Teknoloji:** Three.js ve React kullanmaktadır (GSAP, Vue, Tailwind vb. kullanılmamaktadır).
- **Bizde kullanım:** Görsel ağırlıklı web arayüzleri, prototipler ve pazarlama/sunum sayfaları oluşturma işi için uygundur.
