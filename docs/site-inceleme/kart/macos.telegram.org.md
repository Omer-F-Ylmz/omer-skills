# macos.telegram.org


- **Ne sunuyor**
  - **Etkileşimli sohbet temaları**: 8+ gradyanlı, hareketli arka planlı tema (gündüz/gece mod).
  - **Animasyonlu ifadeler**: Tam ekran efektler (fireworks, party popper vs.) ve titreşimli geri bildirim.
  - **Canlı yayın desteği**: Gruplarda okuma bilgisi ve canlı yayın kaydı.

- **Ücretsiz kısım**
  - MacOS sürümü ücretsiz (Mac App Store’dan indirilebilir).
  - **Beta sürümü** ve **sürüm geçmişi** (v8.1, 20-09-2021) açık.

- **İndirilebilir kaynak/kod**
  - **GitHub**: [TelegramSwift](https://github.com/overtake/TelegramSwift) (GPL v2 lisansı).
  - **JavaScript kütüphanesi**: `macos.telegram.org/js` (3 adet script, animasyon/etkileşim için).

- **Teknoloji**
  - **Kütüphane**: `lib/three.js` (3D animasyonlar için).
  - **Dil**: Swift (TelegramSwift projesinde).

- **Bizde kullanım**
  - **Skill**: **Frontend animasyon** (Three.js), **UI/UX** (temalar, etkileşimler).
  - **İş**: **Mobile/Desktop UI geliştirme**, **sohbet uygulamaları**, **canlı yayın entegrasyonu**.
