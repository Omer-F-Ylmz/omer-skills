# gsap.com


- **GSAP (GreenSock Animation Platform)**
  - **Ne sunuyor**: JavaScript tabanlı, UI, SVG, WebGL ve etkileşimler için siliksmooth performanslı animasyon kütüphanesi.
  - **Ücretsiz kısım**: Tüm kullanıcılar için ücretsiz (Webflow desteğiyle).
  - **İndirilebilir kaynak**: GitHub üzerinden [GreenSock-JS](https://github.com/greensock/GreenSock-JS/) (MIT lisansı). ⚠[kanitsiz]
  - **Teknoloji**: GSAP, GSAP Scroll, GSAP SVG, GSAP Text gibi modüllerle zenginleştirilmiş. ⚠[kanitsiz]
  - **Bizde kullanım**: Web/UX tasarımcılar, front-end geliştiriciler (JS, SVG, WebGL animasyonları için).
