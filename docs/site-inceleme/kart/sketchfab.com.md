# sketchfab.com


- **Ne sunuyor**
  - 3D modellerin interaktif görselleştirilmesi ve paylaşımı.
  - Kullanıcılar tarafından oluşturulan veya indirilen 3D modellerin sergilenmesi.
  - Web tabanlı platform (3D görselleştirme, animasyon, VR destekli).

- **Ücretsiz kısım**
  - Temel kullanım ücretsiz (modeller indirilebilir, paylaşılabilir).
  - Özel lisanslar ve işletimsel kullanım için ücretli seçenekler.

- **İndirilebilir varlık/kaynak kod**
  - 3D modeller (FBX, OBJ, GLTF gibi formatlar) indirilebilir.
  - Kaynak kod **yok** (sadece hazır modeller mevcut).

- **Teknoloji**
  - WebGL tabanlı 3D görselleştirme motoru.
  - WebXR (VR/AR) entegrasyonu.

- **Bizde kullanım**
  - **Skill:** 3D tasarım, animasyon, VR/AR geliştirme.
  - **İş:** Sanal turlar, eğitim materyalleri, dijital sanat sergileri.
