# open-design.ai


- **Ne sunuyor**
  - AI destekli tasarım ajanı (prototipleme, ekip iş birliği) ⚠[kanitsiz]
  - 150+ açık kaynak tasarım sistemi entegrasyonu (renk, tipografi, bileşen yönetimi) ⚠[kanitsiz]
  - Web siteleri, UX/UI, panolar, slaytlar gibi dijital içerikler için prototip oluşturma ⚠[kanitsiz]
  - Kodlama ajanları (Claude, Codex, GitHub Copilot) ile entegrasyon

- **Ücretsiz kısım**
  - Temel özellikler ücretsiz kullanıma sunuluyor (fiyatlandırma sayfası ayrı) ⚠[kanitsiz]
  - Discord topluluğu ve kaynaklar ücretsiz erişim ⚠[kanitsiz]

- **İndirilebilir kaynak/kod**
  - [OpenDesign indirme](https://open-design.ai/tr/download/) ⚠[kanitsiz]
  - [GitHub depoları](https://github.com/nexu-io/open-design) (MIT lisansı) ⚠[kanitsiz]

- **Teknoloji**
  - **Kütüphaneler**: Hiçbir ana kütüphane (Three.js, GSAP, Framer) bağımlılığı yok ⚠[kanitsiz]
  - **Ajan entegrasyonu**: Claude, Codex, Cursor, GitHub Copilot, OpenCode gibi kodlama ajanları ⚠[kanitsiz]
  - **Cloud/Offline**: OpenDesign Cloud + yerel kurulum seçeneği ⚠[kanitsiz]

- **Bizde kullanım (hangi skill/is için)**
  - **Tasarım**: Prototipleme, ekip iş birliği, tasarım sistemleri yönetimi
  - **Geliştirme**: Kodlama ajanları ile entegrasyon, AI destekli UI/UX geliştirme
  - **Marka**: Marka uyumlu dijital içerikler (web, UX, panolar)
  - **Öğrenme**: Tasarım ve kodlama arasında köprü kurma (AI destekli)
