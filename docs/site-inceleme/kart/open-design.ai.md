# open-design.ai


- **Ne sunuyor**
  - AI destekli tasarım ajanı (prototipleme, ekip iş birliği)
  - 150+ açık kaynak tasarım sistemi entegrasyonu (renk, tipografi, bileşen yönetimi)
  - Web siteleri, UX/UI, panolar, slaytlar gibi dijital içerikler için prototip oluşturma
  - Kodlama ajanları (Claude, Codex, GitHub Copilot) ile entegrasyon

- **Ücretsiz kısım**
  - Temel özellikler ücretsiz kullanıma sunuluyor (fiyatlandırma sayfası ayrı)
  - Discord topluluğu ve kaynaklar ücretsiz erişim

- **İndirilebilir kaynak/kod**
  - [OpenDesign indirme](https://open-design.ai/tr/download/)
  - [GitHub depoları](https://github.com/nexu-io/open-design) (MIT lisansı)

- **Teknoloji**
  - **Kütüphaneler**: Hiçbir ana kütüphane (Three.js, GSAP, Framer) bağımlılığı yok
  - **Ajan entegrasyonu**: Claude, Codex, Cursor, GitHub Copilot, OpenCode gibi kodlama ajanları
  - **Cloud/Offline**: OpenDesign Cloud + yerel kurulum seçeneği

- **Bizde kullanım (hangi skill/is için)**
  - **Tasarım**: Prototipleme, ekip iş birliği, tasarım sistemleri yönetimi
  - **Geliştirme**: Kodlama ajanları ile entegrasyon, AI destekli UI/UX geliştirme
  - **Marka**: Marka uyumlu dijital içerikler (web, UX, panolar)
  - **Öğrenme**: Tasarım ve kodlama arasında köprü kurma (AI destekli)
