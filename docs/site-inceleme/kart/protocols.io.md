# protocols.io


- **Ne sunuyor**
  Araştırma yöntemlerini **standartlaştır**, paylaş ve **tekrar edilebilir** kılma platformu.
  - **112K+** araştırmacı tarafından kullanılan **DOI destekli** protokoller.
  - **Güvenilir** metotlar (biyoloji, kimya, veri analizi gibi alanlar).
  - **Kullanıcı dostu** arama ve keşif arayüzü.

- **Ücretsiz kısım**
  - **Kayıtsız** protokoller okuma/ara.
  - **Örnek metotlar** (örn: *ELISA tespiti*, *metabolite ekstraksiyonu*).
  - **Giriş ücretsiz** (özel işlevler için ücretli planlar).

- **İndirilebilir kaynak/kod**
  - **Yok** (protokoller **metin/PDF** olarak indirilebilir, **kod/veri** değil).
  - **Scriptler**: CDN’lerden yüklenen **JavaScript** (örn: `cdnjs.cloudflare.com`).

- **Teknoloji**
  - **Arka plan**: Cloudflare (insights.js), `protocols.io` sunucuları.
  - **Ön uç**: **HTML/CSS/JS** (özel framework/tech yok; kanıtta `lib` boş).

- **Bizde kullanım**
  - **Araştırmacılar** (biyomedikal, ekoloji, veri bilimci) için **yöntem standartlaşması**.
  - **Skill**: **Protokol yazımı**, **veri tekrar edilebilirliği**, **akademik yazım**.
  - **İş**: **Laboratuvar yönetimi**, **bilimsel yazılım**, **veri analizi**.

**Not**: Teknoloji kısıtlı (kanıtta `lib` boş; sadece CDN’ler var). "İndirilebilir kaynak" kod değil, metin/PDF.
