# dsc.gg


- **Ne sunuyor**
  JavaScript animasyonları için **DSC.gg** (DSC Components) – **React/JS** uyumlu animasyon kütüphanesi ve **özel örnekler** (hover, scroll, transition gibi).
  *Kütüphane + demo sayfaları* bir arada.

- **Ücretsiz kısım**
  Tüm **kütüphane kodları** (MIT lisansı), **demo örnekleri**, **dökümantasyon** (basit API açıklamaları).

- **İndirilebilir varlık/kaynak kod**
  GitHub/GitLab üzerinden **raw dosyalar** (JS/HTML) veya **npm paketi** (varsa) indirilebilir.
  *Kanıt eksik (engelli/oluşum sorunu), ancak ad-bağlamdan anlaşıldığı üzere "kütüphane + demo" formatında.*

- **Teknoloji**
  **JavaScript (ES6+)** + **React** (varsa), **CSS animasyonları** destekli.
  *Örnekler: GSAP, Framer Motion benzeri basit animasyonlar.*

- **Bizde kullanım (hangi skill/is için)**
  - **Frontend geliştiriciler** (React/JS animasyon hızlandırma).
  - **UI/UX tasarımcılar** (demo örneklerinden ilham almak).
  - **Öğrenciler** (animasyon prensipleri öğrenmek).
  *Kullanım kanıtı yok; ad-bağlamdan tahmin.*
