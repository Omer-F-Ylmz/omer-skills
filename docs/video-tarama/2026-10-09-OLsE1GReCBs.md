## Özet
Nick Automates, 46 saniyelik kısa videoda yapay zekânın ürettiği sıradan 'AI slop' içeriği azaltmak için dört ücretsiz Claude Code eklentisi tanıtıyor. Impeccable tasarım zevki katıyor. 21st Dev MCP 10.000'den fazla UI bileşeni ve şablon sağlıyor. Humanizer yazıdaki 33 yapay zekâ kalıbını temizliyor ve kullanıcının yazı stilini öğreniyor. Claude Code Setup ise resmi Anthropic eklentisi olarak kod tabanını tarayıp uygun hook, skill, MCP ve alt ajanları kuruyor.
