## Özet
Bruno Souza, Claude Code ile profesyonel görünümlü web siteleri kurmak için üç adım öneriyor. Birincisi tasarım skill'lerini (frontend-design) kurmak. İkincisi Claude Code'u Playwright MCP ile tarayıcıya bağlamak; böylece site masaüstü ve mobilde görülüp düzeltilir. Üçüncüsü 2-3 referans site verip istenen hissi anlatmak. Ekranda jenerik AI tasarımı (IRONCLAD), Kairn sitesinin tarayıcıda kontrol edilip CSS ile düzeltilmesi, igloo.inc referansı ve şablon/özel yapım karşılaştırması (Tellus küre sitesi) görünüyor. Rehber için WEB yorumu isteniyor.
