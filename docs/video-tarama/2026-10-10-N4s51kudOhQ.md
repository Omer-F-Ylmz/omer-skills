## Özet
Burhan Kocabıyık, açık kaynaklı 'videomaker' (GOAT UGC AI) GitHub reposunu Claude Code ile klonlayıp yerelde ve Vercel üzerinde çalıştırmayı gösteriyor. Fal.ai API anahtarıyla Seedance 2.0 (text-to-video) ve Nano Banana 2 (image-to-video) akışları denenir. LTX 2 için hazırlanmış bir prompt kütüphanesi incelenir. Fal tarafı ilk başta takılır, Claude Code düzeltir ve videolar üretilir. Yazı bozulması için image-to-video önerilir. Sonda Skool topluluğu (DOA) tanıtılır.
