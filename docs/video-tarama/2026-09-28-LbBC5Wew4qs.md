## Künye
Claude Code + OpenAI Codex İki Dev Yapay Zekayı Aynı Anda Kullan · Burhan KOCABIYIK · süre: 13:57 · dil: tr · https://youtu.be/LbBC5Wew4qs

## Özet
Video, Claude Code içine OpenAI Codex'i plugin olarak kurup ikisini birlikte kullanmayı anlatıyor. Önce Claude Opus ile Codex'in (ChatGPT GPT-5.4 tabanlı) güçlü/zayıf yönleri karşılaştırılıyor: Claude planlama ve mimaride, Codex kod inceleme/hata tespitinde ve token verimliliğinde öne çıkıyor. VS Code üzerinde Claude Code çalıştırılıp `/plugin marketplace add` ve `/plugin install` komutlarıyla Codex marketplace ve plugin'i kuruluyor, `codex configure --chatgpt` ile mevcut ChatGPT aboneliğine bağlanıyor (ekstra API anahtarı gerekmiyor). Önerilen iş akışı: mimariyi ve ilk kod taslağını Claude Code yazsın, Codex `/review` ile derin hata taraması yapıp bulguları bir log dosyasına yazsın, sonra Claude Code plan modunda sadece o log'daki hataları çözsün — bu da Claude'un tüm dosyaları yeniden tarama maliyetini azaltıyor. Kanal sahibi kullanım oranı olarak proje büyüklüğüne göre %80/%20'den %30/%70'e kadar değişen Claude/Codex dağılımı öneriyor. İçerik bir CLI/plugin kurulum ve iş akışı videosu; frontend/site yapımı içermiyor.
