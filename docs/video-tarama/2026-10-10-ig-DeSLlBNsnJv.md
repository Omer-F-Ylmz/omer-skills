## Özet
Cloudflare'in yayınladığı, vibe coding ile yazılmış uygulamalardaki güvenlik açıklarını bulan ücretsiz bir Claude Code skill'i tanıtılıyor. Skill uygulamanın haritasını çıkarır, bir ajan ekibi saldırgan gibi kodu okur (login bypass, SQL injection, API yetkilendirme, prompt injection) ve doğrulanmış açıklar ile düzeltme önerilerini içeren bir rapor üretir. Cloudflare kendi kod tabanında 7000'den fazla sorun bulmuş, repo GitHub'da 25 bin yıldıza ulaşmış. Skill linki yorumlara sabitlenmiş, ancak yorumlar girişsiz alınamadı.
