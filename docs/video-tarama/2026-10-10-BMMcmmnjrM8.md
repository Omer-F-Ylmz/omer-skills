## Özet
Nick Saraev'in 4 saatlik kursu: Claude Code ile Expo/React Native kullanarak mobil uygulama geliştirme. Kurulum (Claude, Antigravity, Claude Code eklentisi, Expo Go), 5 adımlı uygulama tasarım çerçevesi (çekirdek işlev, çekirdek döngü, yardımcı özellikler, yüzey alanı kontrolü, tutundurma kancası), alışkanlık takibi uygulaması, Supabase veritabanı ve kimlik doğrulama, Claude API ile akıllı koçluk (Supabase Edge Functions), güvenlik denetimi istemi, Cal AI benzeri kalori takip uygulaması, GPT Image 2 ile üretilen görsellerle Pomodoro ağaç büyütme uygulaması ve EAS ile App Store'a gönderim anlatılıyor. Kare görseli yok; tüm bilgiler altyazı ve açıklamadan alındı.
