Instagram kaydırmalı gönderisi: Claude Code ile tarayıcı otomasyonu için MCP yerine Playwright CLI kullanmayı öneriyor. MCP sunucuları her aracın açıklamasını yüklediği için token harcıyor. Kurulum rehberi yorumlara 'BECERI' yazanlara DM ile gönderiliyor.
