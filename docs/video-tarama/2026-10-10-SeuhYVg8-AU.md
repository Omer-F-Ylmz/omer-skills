## Özet
Smitha Kolan, Google Cloud Shell içinde Gemini CLI'yi ana ajan olarak kullanarak Google'ın uzak MCP sunucularıyla (Developer Knowledge, Cloud SQL, Cloud Run) AllStrides adlı full stack uygulamayı yerelden buluta taşıyor. Önce dokümantasyon araması ile veritabanı seçimi (Cloud SQL for PostgreSQL) yapılıyor, ardından Cloud SQL örneği oluşturulup veri taşınıyor, son olarak uygulama Cloud Run'a dağıtılıp çalışan site gösteriliyor.
