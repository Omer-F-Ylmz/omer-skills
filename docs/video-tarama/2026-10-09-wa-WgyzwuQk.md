## Özet
İsa Nurdoğdu 40 saniyelik bu kısa videoda Claude Code ile tek komutla web sitesi kurmayı anlatıyor. Önce Claude Code resmi dokümandan kuruluyor. Sonra animasyon için Framer Motion (motion paketi) ekleniyor. Ardından tasarım sistemi için UI UX Pro Max arayüz yetenekleri yükleniyor (uipro init --ai claude). Son olarak 21st.dev gibi bir bileşen sitesinden kod kopyalanıp Claude Code'a yapıştırılıyor. Sonuçta ürün tanıtım sitesi çıkıyor ve müşteriye satılabileceği söyleniyor. Yoruma 'kod' yazılması isteniyor; rehber bağlantısı açıklamada.
