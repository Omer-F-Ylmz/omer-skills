# Claude Code ile Premium Animasyonlu Web Sitesi Yaptım
## Künye
Claude Code ile Premium Animasyonlu Web Sitesi Yaptım · Yıldız Dikme · süre: 14:38 · en · https://youtu.be/4cE9t4rE0-0

## Özet
Video başlığına rağmen içerik Claude Code değil, Abacus AI'ın çoklu-model platformu ChatLLM üzerinden anlatılıyor. Yıldız Dikme, tek platformda hem video hem görsel hem kod üretebildiğini gösteriyor: önce ChatLLM'in genel arayüzünü (RouteLLM otomatik model seçimi, Agent modu, capability eklentileri, performans seviyeleri) tanıtıyor. Sonra bir yat teması için ilk/son sahne vererek Kling AI v3 ile 8 saniyelik tanıtım videosu üretiyor. Bu videoyu Agent bölümüne yükleyip detaylı bir prompt (renk paleti, font, scroll davranışı, teknoloji) vererek scroll'a bağlı video-scrub animasyonlu bir yat web sitesini GSAP/ScrollTrigger tabanlı kodla sıfırdan ürettiriyor. Ardından siteyi Abacus'un kendi subdomain'i ile tek tıkla yayınlıyor, kendi domain bağlama seçeneğini gösteriyor. Kapanışta profil sayfasından kredi/token tüketimini (20.000 kredi üzerinden ~7.200 kullanılmış) gösterip kredilerin token ile aynı şey olmadığını vurguluyor.
