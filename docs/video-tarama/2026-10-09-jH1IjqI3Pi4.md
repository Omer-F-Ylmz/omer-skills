## Özet
Video, Claude Code'a gelen resmi Mods özelliğini anlatır: mod, Claude Code içinde çalışan küçük bir JS/TS plugin'idir. Ekranı yeniden çizer, panel/bant/buton ekler, tool çağrılarını durdurur ve token harcamayan /komutlar ekler. Güvenlik uyarıları (kullanıcı yetkisi, sandbox dışı; claude plugin validate, --safe-mode) verilir. Sonra Claude'a yaptırılan Kod Kedisi, Maç Spikeri, Bekçi Murtaza ve Hoca Paneli modları test edilir.
