## Özet
Nate Herk, Claude Code ile yapay zekâ işi gibi görünmeyen, profesyonel ve markaya uygun web siteleri üretmek için beş ipucu anlatıyor. Kurulum VS Code ve Claude Code eklentisiyle yapılıyor. İpuçları: (0) CLAUDE.md dosyası, (1) frontend-design skill, (2) Puppeteer ile ekran görüntüsü döngüsü, (3) başka siteleri referans alıp klonlama, (4) 21st.dev'den tekil bileşenler. Sonda proje GitHub'a itilip Vercel ile otomatik yayına alınıyor. Yerelde test edip istenince push etme akışı gösteriliyor.
