## Özet
DeepSeek'in model değil, açık kaynak AI coding aracı DeepSeek Harness (dsh) tanıtılıyor. 'Everything is a Plugin' mantığıyla model, tool, skill, session, sandbox, storage ve arayüz değiştirilebiliyor. Kurulum tek npx komutuyla yapılıyor, Web UI açılıyor. Standard, Code (PTC), Minimal ve Creator modları var; Creator modda tek promptla robot maskot plugin'i oluşturuluyor.
