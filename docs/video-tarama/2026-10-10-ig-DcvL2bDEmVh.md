## Özet
35 saniyelik reel. Sunucu, ChatGPT ve Gemini gibi büyük modellerin neye cevap vereceğine dair sert sınırları olduğunu söylüyor. Ardından Heretic'i tanıtıyor. Heretic, açık kaynak modellerdeki reddetme davranışını otomatik kaldıran bir Python kütüphanesi. Modelin içinde reddetmeyi tetikleyen kalıpları bulup siliyor. Sunucuya göre bunu modelin zekâsına ve performansına zarar vermeden yapıyor. Ekranda terminal çıktısı (gpt-oss-20b yükleme, veri setleri, batch size denemesi), Heretic proje sayfası, GitHub deposu ve README kurulum komutları görünüyor. Açıklamada 28 bin yıldız yazıyor, seste 20 bin deniyor. Videonun sonlarında Claude Code skills kurulumuna dair ilgisiz bir rehber ekranı var. Sunucu, denemek isteyenlerin yorumlara model yazmasını istiyor.
