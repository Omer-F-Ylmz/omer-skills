# MiniMax'i Claude Code'a Bağlayıp Token Masrafını 5x Düşürün

## Künye
MiniMax'i Claude Code'a Bağlayıp Token Masrafını 5x Düşürün · Burhan KOCABIYIK · süre: 12:13 · dil tr-orig · https://youtu.be/XemheY_aM1g

## Özet
Video, Claude Code içinde pahalı Opus modeli yerine çok daha ucuz MiniMax M3 modelini kullanarak token maliyetini düşürmeyi anlatıyor.
Anlatıcı önce kendi GOAT adlı SaaS ajan ürününü örnek göstererek çok token harcayan otomatik görev akışlarına giriş yapıyor.
Ardından MiniMax platformunda API anahtarı oluşturma ve bakiyeye ödeme yükleme adımlarını gösteriyor.
Claude Code terminalinde `claude` komutu Opus'u, `claude /mm` ("claude-mm") komutu ise MiniMax'i başlatıyor; ikisi ayrı terminal pencerelerinde eşzamanlı kullanılabiliyor.
İki test yapılıyor: ekran görüntülerinden 100 e-posta şablonu üretme ve bir arayüz görselinden benzer arayüz/kod üretme.
MiniMax'in görsel okuma, kod üretme ve 1 milyon token context desteğiyle Opus'a yakın sonuç verdiği; fiyatının ise 5-6x daha ucuz olduğu (bu işte ~5 cent vs tahmini ~200 cent) gösteriliyor.
Kapanışta mevcut %50 indirime ek %12'lik indirim kodu paylaşılıyor.
