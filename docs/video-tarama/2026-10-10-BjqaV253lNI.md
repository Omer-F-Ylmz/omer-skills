## Özet
Ömer Göçmen, LLM'lerin eski ve uydurma bilgi verme sorununu çözmek için Upstash'ın Context7 MCP sunucusunu tanıtıyor. GitHub README'sini gezip gereksinimleri (Node.js 18+, bir MCP istemcisi) ve kurulum yollarını (Cursor, Windsurf, VS Code, Claude Desktop/Code, Docker) anlatıyor. Cursor'daki mcp.json yöntemi kendisinde 'client closed' hatası verdiği için Smithery hesabı, API key ve npx @smithery/cli komutuyla Windsurf'e kuruyor. Windsurf Cascade'de Next.js onNavigate sorusunu önce Context7'siz, sonra sonuna 'use context7' ekleyerek soruyor; ikincisi güncel dokümandan Link örnekleri getiriyor. Son olarak context7.com'da 5000 token varsayılanını ve konu aramasını gösteriyor.
