## Özet
İsa Nurdoğdu, Claude Code'un gereğinden fazla kod üretmesini azaltan Ponytail skill/eklentisini tanıtıyor. Ponytail, kod yazmadan önce kısa bir kontrol listesi uygulatır: ihtiyaç var mı, standart kütüphane yapıyor mu, yerel platform özelliği, kurulu bağımlılık, tek satır. Geliştiricinin testinde Ponytail olmadan 445 satır üretilirken skill ile çıktı neredeyse yarıya indi (açıklamada 246 satır). Kurulum Claude Code içinde /plugin komutlarıyla yapılıyor; videoda linki Claude'a verip kur demek yeterli deniyor.
