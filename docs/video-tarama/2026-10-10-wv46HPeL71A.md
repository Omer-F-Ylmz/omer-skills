## Özet
İsa Nurdoğdu, açık kaynak OpenMontage reposunu Claude Code ile VS Code içinde kurarak video editlemeyi gösteriyor. Pexels/Pixabay stok görselleri, Google görselleri ve Remotion grafik animasyonlarıyla 8 dakikaya kadar videoyu tek prompt'la kurguluyor. Ücretsiz API anahtarları (Pexels, ElevenLabs), ücretli fal.ai alternatifi, TurboScribe ile zaman damgalı transkript, iki yöntemin (stok+grafik / yalnız Apple tarzı grafik) karşılaştırması ve geri bildirimin hafızaya kaydedilmesi anlatılıyor. Claude Code video üretmiyor, kod yazıp Remotion ile render alıyor; AI video modelleri ayrıca bağlanmalı.
