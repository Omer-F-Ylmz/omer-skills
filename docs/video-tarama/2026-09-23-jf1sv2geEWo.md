## Özet
Sunucu, Claude Code için viral olan "Caveman" skill/plugin'ini test ediyor; iddia %65-75 token tasarrufu. Aynı uzun implementasyon promptunu Caveman'sız ve Caveman'lı iki ayrı Claude Code oturumunda (Opus 4.7, high effort) çalıştırıp `/usage` panelinden oturum yüzdesini karşılaştırıyor. Her iki koşuda da kullanım aynı (%4) çıkıyor; Caveman yalnız terminaldeki iletişim metnini kısaltıyor ama asıl token tüketimi thinking ve kod üretiminde, iletişimde değil. Reddit'te bazı kullanıcılar %30 azalma bildiriyor, bir yorum "maliyeti yaratan prompt değil, thinking" diyor. GitHub README'sindeki örnek 69→19 token (%75 azalma) gösteriyor ama bu tek cümlelik izole bir örnek, gerçek oturum davranışını yansıtmıyor. Sonuç: sunucu Caveman'ı abartılı hype buster olarak değerlendiriyor, yine de sohbet ağırlıklı (kod üretimi az) senaryolarda faydalı olabileceğini düşünüyor.
