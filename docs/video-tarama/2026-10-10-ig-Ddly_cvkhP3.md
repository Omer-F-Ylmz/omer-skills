## Özet
Alperen Erbay, 200'den fazla görsel/video modelini (Sora, Kling, Flux, Midjourney vb.) tek arayüzde toplayan ücretsiz, açık kaynak 'Open-Generative-AI' (MuAPI) stüdyosunu tanıtıyor. GitHub'da yaklaşık 10.700 yıldız olduğunu, sinema kamera/lens/diyafram kontrolleri bulunduğunu söylüyor. Kurulum: GitHub linkini aç, tek tıkla kurulumu çalıştır (~2 dk), model seç, prompt yaz, üret. Claude Code ve Codex'e bağlanabildiği belirtiliyor. Sonunda 'stüdyo' yorumuna rehber ve link vaadi var; rehber kareleri Claude Code'a yapıştırılacak kurulum promptlarını gösteriyor.
