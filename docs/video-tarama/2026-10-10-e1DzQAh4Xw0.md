## Özet
Ömer Göçmen, n8n ve Dumpling AI ile üç iş ilanı sitesinden (kariyer.net, LinkedIn, eleman.net) ilanları otomatik toplayan bir akış kuruyor. Dumpling AI scrape endpoint'i HTML döndürüyor; Extract HTML node'ları CSS seçicilerle link, başlık, firma, şehir ve diğer bilgileri ayıklıyor. Kaynaklar Merge ile birleşiyor, Filter son iki haftanın ilanlarını bırakıyor, Aggregate + Code + Generate HTML ile tablo oluşturulup Gmail ile e-postaya gönderiliyor. Sonda Dumpling AI Web Scraping Agent hem arayüzde hem Postman ile API üzerinden gösteriliyor.

## İş akışı
- 1. adım — Dumpling AI dokümantasyonu ve dashboard'u incelenip scrape endpoint'i ile kredi maliyetleri karşılaştırıldı. — araçlar: Dumpling AI, Dumpling AI Scrape
- 2. adım — Dumpling AI'da API key oluşturulup n8n HTTP Request node'una Bearer header olarak eklendi. — araçlar: Dumpling AI, HTTP Request, n8n
- 3. adım — kariyer.net'te filtreli (son 15 gün) arama URL'si alınıp birinci scrape node'una yazıldı (cleaned true). — araçlar: kariyer.net, HTTP Request, Dumpling AI Scrape
- 4. adım — LinkedIn için arama URL'si alınıp ikinci scrape node'una yazıldı. — araçlar: LinkedIn, HTTP Request, Dumpling AI Scrape
- 5. adım — eleman.net için filtreli URL alınıp üçüncü scrape node'una yazıldı (cleaned false). — araçlar: eleman.net, HTTP Request, Dumpling AI Scrape
- 6. adım — DevTools ile ilan, başlık, firma ve link elemanları incelenip CSS seçiciler belirlendi. — araçlar: Chrome DevTools, CSS seçiciler
- 7. adım — Extract all jobs ile ilan kartları dizi olarak çıkarıldı. — araçlar: Extract HTML Content, CSS seçiciler
- 8. adım — Extract job props ile link, başlık, firma, şehir ve diğer (Etc) alanları ayıklandı. — araçlar: Extract HTML Content, CSS seçiciler
- 9. adım — Tarih filtresi olmayan kaynakta Etc alanına göre 1 hafta/2 hafta/gün filtresi uygulandı (60 → 34). — araçlar: Filter
- 10. adım — Üç kaynak Append modunda birleştirildi (76 öğe). — araçlar: Merge
- 11. adım — Öğeler data altında tek listeye toplandı. — araçlar: Aggregate
- 12. adım — JavaScript ile ilanlar HTML tablo satırlarına çevrildi. — araçlar: Code node (JavaScript)
- 13. adım — Tablo CSS ile stillenip \n karakterleri temizlenerek HTML şablonu üretildi. — araçlar: Generate HTML Template
- 14. adım — Gmail node'u Google OAuth ile bağlanıp HTML e-posta 'iki haftalık iş ilanları' konusuyla gönderildi. — araçlar: Gmail, Google OAuth
- 15. adım — Workflow Test workflow ile çalıştırıldı; e-posta Gmail'de doğrulandı (64 ilan). — araçlar: n8n, Gmail
- 16. adım — Alternatif olarak Web Scraping Agent oluşturulup eleman.net URL'si ile denendi. — araçlar: Dumpling AI Agents, Web Scraping Agent
- 17. adım — Agent, generate-completion endpoint'iyle Postman'de API üzerinden çağrıldı. — araçlar: Postman, Dumpling AI Generate Agent Completion
