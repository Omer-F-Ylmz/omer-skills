## Özet
Calvin Hia, Claude Code ile Seedance 2.0 Mini ve GPT Image 2 kullanarak 3B kaydırmalı ürün web siteleri üretmeyi gösteriyor. Önce örnek siteler (Velo ayakkabı, Pulse kulaklık, Huriza robot) gösteriliyor. Ardından ücretsiz 3D Webpage Kit kuruluyor: VS Code, Claude Code eklentisi, kie.ai API anahtarı, Cloudflare token, Homebrew ile FFmpeg. Canlı olarak Maison Doré / Dorée 38 saat sayfası marka kurulumu, storyboard, Seedance videosu, kare üretimi ve Cloudflare Workers'a yayınla tamamlanıyor.
