## Özet
Eric Tech, Anthropic'in Boris Cherny ve ekibinin yayımladığı 'AI-Native SDLC Playbook'u Claude Code ile anlatıyor. Planlama (grilling skill ile intent.md), tasarım (spec.md), plan.md, test odaklı geliştirme (test/lint/build yeşil olmadan 'bitti' deme), test katmanları (Jest/Vitest, React Testing Library, Cypress/Playwright), CI'da sürekli eval, PR inceleme (REVIEW.md), hook'lar, dağıtım (claude -p, MCP ile deploy/status/rollback, Datadog/Sentry) ve metriklerle döngüyü kapatma (yeni intent.md) adım adım işleniyor. Videoda Skool topluluğu ve Johns Hopkins Agentic AI sertifika programı (Great Learning) tanıtımı var.
