## Özet
Burhan Kocabıyık, kendi ürünü GOAT için yapılmış tanıtım videosunun tamamının Claude Code ve Remotion ile ücretsiz üretildiğini söylüyor. Visual Studio Code içindeki terminale Claude Code kuruyor. 'command not found: claude' hatasını PATH komutuyla çözüyor. Sesle yazdığı tek bir prompt veriyor. Prompt Remotion projesi, bölüm ve başlık kartları, geçişler, altyazı, seslendirme ve yaklaşık 1 dakikalık süre istiyor. Claude Code Remotion'ı kuruyor, thegoat.bot sitesini çekiyor ve ücretsiz edge-tts ile seslendirme üretiyor. Apify anahtarı verilse de siteyi düz curl ile çektiği için Apify'a gerek kalmıyor. Videonun ana savı, terminal ve yerel bilgisayar kullanmanın bulut sohbet arayüzünden çok daha fazla iş yapabilmesi.
