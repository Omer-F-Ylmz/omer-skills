## Özet
Nick Saraev, Claude Code arayüzünü aynen koruyup arkada ucuz/ücretsiz modelleri kullanmayı sağlayan açık kaynaklı 'free-claude-code' vekil sunucusunu (localhost:8082) anlatıyor. Repo kurulumu (uv, Python 3.14, git clone, .env), ardından üç sağlayıcı sırayla gösteriliyor: OpenRouter (DeepSeek V4 Flash ile 'Habitual' alışkanlık takip uygulaması), NVIDIA NIM (ücretsiz GLM 4.7) ve Ollama (yerel Gemma 4). Fast mode hatası, statusline değişikliği, 50 bin token'da yeni oturum ipucu ve Opus'un orkestratör, DeepSeek'in alt ajan olduğu kalori takipçisi demosu da var. Video sonunda Maker School reklamı yer alıyor.
