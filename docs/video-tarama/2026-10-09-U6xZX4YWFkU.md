## Özet
Mert Durmazer, Claude Code'a gelen 'Claude Mods' özelliğini anlatıyor. Mod'lar, Claude Code olaylarına bağlanan küçük TypeScript fonksiyonlarıdır; plugin içinde gelir. Önce topluluk örnekleri (oyun, Shorts, nefes egzersizi, hatırlatıcı, Xcode paneli, dosya ağacı, ajan panosu, önbellek bekçisi, env kartı) gösterilir. Sonra fikrin kökeni anlatılır: Boris Cherny'nin 3 Eylül paylaşımı, GitHub #91870 başlığı, 1 Ekim'de Claude Code 2.1.287 ile herkese açılması. Ardından canlı olarak üç mod yazdırılır: güvenli-silme, sonraki-adımlar ve önbellek-saati. Son bölümde kullanım denetimi promptu, güvenlik uyarıları (mod'lar kullanıcı yetkisiyle çalışır) ve claude plugin validate / --safe-mode önerileri yer alır.
