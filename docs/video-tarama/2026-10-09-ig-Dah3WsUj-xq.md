## Özet
Kısa reel, wget ve archiver üzerine kurulu açık kaynaklı 'Website Downloader' aracını tanıtıyor. Araç bir sitenin sayfalarını, JavaScript, CSS ve görsellerini indirip bağlantıları çevrimdışı çalışacak şekilde yeniden yazıyor. HTTrack'e ücretsiz alternatif olarak sunuluyor. Web arayüzüne URL yapıştırarak ya da git clone, npm install, npm start komutlarıyla yerelde çalıştırılıyor.
