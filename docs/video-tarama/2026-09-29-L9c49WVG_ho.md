## Özet
Kısa video, ücretsiz kullanılabilen yüzlerce LLM API'sini listeleyen bir GitHub reposunu tanıtıyor. Repo Kimi ve DeepSeek gibi modellere de ücretsiz erişim veriyor. İzleyici OpenRouter, Groq veya Nvidia NIM gibi bir sağlayıcı seçip oradan API anahtarı üretiyor. Anahtar Claude Code ya da Cursor'a veriliyor ve ajan ücretsiz çalışıyor. Aynı yöntem uygulamanın içindeki basit işler için de kullanılabiliyor. Ajan Claude'da kalabilir, basit işlemler ücretsiz modele devredilebilir. Kurulum ayrıntıları yorumda paylaşılmış, açıklamada bağlantı yok.
