## Özet
AI Engineer World's Fair 2025, 1. gün kayıtlı keynote ve MCP track (8:37:51). Açılış ve ana konuşmalar (Swix, Microsoft Foundry ve GitHub Copilot demoları, Sarah Guo, Simon Willison'ın LLM yıl özeti ve pelican benchmark'ı, Neo4j Graph RAG demosu). MCP track'te Anthropic'in uzak MCP desteği, VS Code MCP spec desteği, Sentry MCP deneyimi, Pydantic AI ile MCP sampling, W&B Weave/OpenTelemetry ile MCP gözlemlenebilirliği ve Apify ile ajan ekonomisi anlatılıyor. Kapanışta AWS Strands/Lambda MCP demosu, Windsurf'ün ajan stratejisi ve Greg Brockman söyleşisi var. Video konuşmacı ağırlıklı, çoğu bölüm araç tanıtımı; kurulum adımları sınırlı.
