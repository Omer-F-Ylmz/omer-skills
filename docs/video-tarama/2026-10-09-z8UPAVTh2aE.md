## Özet
Miraya, GitHub profilini öne çıkarmayı ve projeleri doğru belgelemeyi anlatıyor. Google ile hesap açıp profil bilgilerini (ad, bio, konum, yerel saat, bağlantılar, durum, avatar) dolduruyor. Kullanıcı adıyla aynı adlı özel README deposunu oluşturuyor. README'nin sade ve 10 saniyede anlaşılır olması gerektiğini, rozetlerin takipçiden değerli olduğunu söylüyor. Sonda NinjaSketch (ayrıntılı) ve Anime Scene Gallery (minimal) README örneklerini gösteriyor.
