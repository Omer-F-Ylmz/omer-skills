## Özet
NetworkChuck, Docker Desktop'taki MCP Toolkit'i açıp Claude'a Kali Linux araçlarını veren özel bir MCP sunucusu kurar. Hazır bir prompt Claude'a Dockerfile, Python sunucusu, requirements ve readme ürettirir. Dosyalar kaydedilir, docker build ile imaj derlenir, sunucu Docker MCP gateway'e bağlanır ve Claude yeniden başlatılır. Claude sonra nmap taraması ve DVWA test sunucusunda zafiyet taraması yapar. Konteyner yalnız çalışırken ayakta kalır.
