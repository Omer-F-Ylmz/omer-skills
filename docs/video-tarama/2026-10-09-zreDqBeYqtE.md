## Özet
Reallusion eğitimi: Unreal Auto Setup (All-in-One) eklentisinin yeni özelliğiyle, CC karakterine MetaHuman Groom saçı Control Rig Blueprint ya da Live Link üzerinden uygulanır. Karakter CC5'ten FBX olarak aktarılır, Unreal'e Control Rig ile alınır, Sequencer'a eklenir. MetaHuman Creator çekirdek verisi etkinleştirilir, groom asset ve binding bulunur. 'Create CC Groom Binding' ile UV/konum verisi CC karakter mesh'ine aktarılır. Orijinal saç opaklığı sıfırlanır, malzeme ayarlanır. Aynı yöntem iClone Live Link blueprint'inde de gösterilir.

## İş akışı
- 1. adım — Character Creator 5'te karakteri açıp Animation Player'da animasyonu hazırlama — araçlar: Character Creator 5
- 2. adım — Export FBX penceresinde Unreal (UE5 Skeleton) preset'i, Mesh and Motion seçeneği ve SubD 1 ayarını seçme — araçlar: Character Creator 5
- 3. adım — Current Animation seçip karakteri FBX olarak dışa aktarma — araçlar: Character Creator 5
- 4. adım — Unreal Engine'de Content Drawer'dan Import ile FBX dosyasını içe aktarma — araçlar: Unreal Engine 5.7
- 5. adım — FBX import ayarlarında Import Morph Targets ve Import Animations'ı etkinleştirip Control Rig oluşturmayı seçme — araçlar: Unreal Engine 5.7, Control Rig
- 6. adım — Control Rig Blueprint'i sahneye sürükleme ve karakteri Sequencer'a ekleme — araçlar: Sequencer, Control Rig
- 7. adım — Animasyonu body ve face track'lerine uygulama, Control Rig'i mute etme ve Animation Mode'u Custom olarak ayarlayıp önizleme — araçlar: Sequencer, Control Rig
- 8. adım — Epic Games Launcher'da Unreal Engine 5.7 seçenekleri içinde MetaHuman Creator Core Data'yı etkinleştirip Apply etme — araçlar: Epic Games Launcher
- 9. adım — Unreal Plugins menüsünden MetaHuman Creator eklentisini etkinleştirme — araçlar: Unreal Engine 5.7, MetaHuman Creator
- 10. adım — Content Drawer'da MetaHuman Creator Content > Optional > Grooms > GroomAssets > Hair yolunda saç asset'ini seçip önizleme — araçlar: MetaHuman Creator
- 11. adım — Control Rig Blueprint'te Components panelinden Groom component ekleyip Face altına yerleştirme ve saç asset'ini slota sürükleme — araçlar: Control Rig, Unreal Engine 5.7
- 12. adım — Grooms > Bindings klasöründen saça karşılık gelen binding'i bulma ve saç asset'inde Create CC Groom Binding ile source ve target ayarlama — araçlar: MetaHuman Creator, Unreal Auto Setup, Groom Binding
- 13. adım — Karakter klasöründeki groom asset ve binding'i karaktere uygulama, face component'te saç materyali atayıp orijinal saçı opacity sıfırla gizleme — araçlar: Unreal Engine 5.7, Groom Binding
- 14. adım — Blueprint'i Compile edip Sequencer'da animasyonu oynatarak sonucu kontrol etme; saç materyal parametrelerini düzenleme — araçlar: Unreal Engine 5.7, Sequencer
- 15. adım — iClone 8'de animasyonlu karakteri Unreal Live Link Transfer ile Unreal'e aktarma — araçlar: iClone 8, Unreal Live Link
- 16. adım — Unreal'de Live Link source ekleyip karakteri seçme ve Link'i etkinleştirme — araçlar: Live Link, Unreal Live Link
- 17. adım — Live Link Blueprint'ine Groom component ekleyip saç asset'ini uygulama, Create CC Groom Binding ile binding oluşturma ve Compile etme — araçlar: Live Link, Unreal Auto Setup, Groom Binding
