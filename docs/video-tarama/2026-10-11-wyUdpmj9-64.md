## Özet
AI Engineer Paris 2025'in 2. gün ana sahne programı. Neo4j (veri katmanı, bilgi grafiği, agentic bellek), Docker (agent paketleme, MCP Toolkit ve kataloğu), GitHub (MCP protokolü ve ölçekte dersler), Koyeb (sandbox, agent altyapısı, bellek snapshot), Black Forest Labs (FLUX modelleri, latent flow matching), H Company (Surfer-H tarayıcı ajanı, Holo modelleri), Hugging Face (açık LLM'ler 2025), Arize (system prompt learning), ZML (CPU üzerinde attention, DPDK), LlamaIndex (Notebook Llama), Google DeepMind (Gemini 2.5 Pro, Veo 3, Genie 3, AI Studio) ve Kyutai (Moshi, Mimi, gerçek zamanlı ses) konuşmalarının kaydı.
