# Claude'a Awwwards Ödüllü Siteden 3D Sinematik Web Site Yaptırdım
## Künye
Claude'a Awwwards Ödüllü Siteden 3D Sinematik Web Site Yaptırdım · Yıldız Dikme · süre: 12:46 · dil: en · https://youtu.be/b-LZ_Y9wor8

## Özet
Yıldız Dikme, Awwwards ödüllü özel jet sitesi jeskojets.com'u inceleyip aynı sinematik anlatıyı kendi portföy sitesine uyarlıyor. Uçak penceresinden içeri giren kaydırma deneyimi, kağıt gibi savrulan proje slider'ı, 3D jet modeli ve "global" temalı dünya haritası footer'ı analiz ediliyor. Ardından Claude'a (Opus model) çok uzun ve detaylı bir prompt gönderip Next.js + GSAP + WebGL + Lenis yığınıyla siteyi sıfırdan kurduruyor; dosya yapısını prompt içinde kendisi belirliyor. Site ~25 dakikada üretiliyor, localhost:3000'de test ediliyor. Sonuç incelenirken küçük konumlama/tipografi kusurları not ediliyor ama genel yapı ve efektler doğru çalışıyor. Video, tasarım ilhamı → detaylı prompt → tek seferde üretim iş akışını örnekliyor; prompt'un kendisi videoda okunmuyor, Google Drive linkiyle paylaşılıyor.
