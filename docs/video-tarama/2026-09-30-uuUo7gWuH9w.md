## Özet
Tech With Tim, Claude Code için gerçekten işe yarayan 7 plugin/MCP aracını anlatıyor. Çok fazla araç (yaklaşık 50'yi aşınca) Claude'un yanlış araç seçtiğini söyleyip seçici olmayı öneriyor. Plugin ile MCP farkını ve marketplace mantığını açıklıyor. Liste: Pyright LSP, GitHub MCP (resmi plugin bozuk, PAT ile elle kurulum), Frontend Design, Tiger Data MCP (Postgres/TimescaleDB, fork ve hypertable ile sorgu hızlanması, sponsorlu), Context7, Composio MCP ve Figma.
