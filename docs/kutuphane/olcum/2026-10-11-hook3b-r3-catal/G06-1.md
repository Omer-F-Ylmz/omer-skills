En güncel kararlı Playwright sürümü **v1.64.0** (7 Ekim 2026'da yayınlandı). Hem npm'de `latest` etiketi hem de GitHub'daki "latest release" bu sürümü gösteriyor.

Trace viewer'ı CLI'dan açmak için:

```bash
npx playwright show-trace path/to/trace.zip              # yerel dosya (tam yol verin)
npx playwright show-trace https://example.com/trace.zip  # uzak URL
```

Diğer diller için:
- **Python:** `playwright show-trace trace.zip`
- **.NET:** `pwsh bin/Debug/netX/playwright.ps1 show-trace trace.zip`
- **Java:** `mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI -D exec.args="show-trace trace.zip"`

Hiçbir şey kurmadan açmak isterseniz trace dosyasını https://trace.playwright.dev sayfasına sürükleyip bırakabilirsiniz. Bu sayfaya `?trace=<url>` parametresiyle bir URL de verebilirsiniz, ancak bu durumda CORS kuralları uygulanabilir.
