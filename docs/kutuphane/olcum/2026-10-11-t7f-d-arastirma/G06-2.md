**Trace viewer'ı CLI'dan açmak için:**
```
npx playwright show-trace path/to/trace.zip
```
Uzaktaki bir trace dosyasını URL ile de açabilirsin:
```
npx playwright show-trace https://example.com/trace.zip
```
Hiçbir şey kurmadan açmak istersen https://trace.playwright.dev sayfasına zip dosyasını sürükleyip bırakman yeterli. Trace tamamen tarayıcında yükleniyor, dışarıya veri gönderilmiyor.
