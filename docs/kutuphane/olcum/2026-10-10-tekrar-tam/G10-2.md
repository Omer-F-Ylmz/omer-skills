```html
<h1 class="baslik">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)", () => {
    gsap.from(".baslik", {
      y: 40,          // 40px aşağıdan başlar, 0'a kayar
      autoAlpha: 0,   // opaklık 0→1, başlangıçta visibility:hidden
      duration: 0.8,
      ease: "power2.out",
    });
  });
</script>
```

- Animasyon sayfa yüklenince bir kez çalışır. ScrollTrigger kullanılmadığı için scroll'la bir bağlantısı yok.
- `autoAlpha` opaklığı ayarlarken `visibility` özelliğini de yönetir. `opacity`'den farkı, başlık şeffafken tıklanabilir kalmamasıdır.
- Sistemde "hareketi azalt" ayarı açık olan kullanıcılarda animasyon çalışmaz, başlık doğrudan görünür.

Bir dosyaya yazmadım ve tarayıcıda çalıştırıp denemedim, kodu yanıt olarak verdim. React içinde kullanacaksanız aynı `gsap.from` çağrısını `useGSAP` hook'unun içine koymanız yeterli.
