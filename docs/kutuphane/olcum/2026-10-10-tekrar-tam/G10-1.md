```html
<h1 class="baslik">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
    gsap.from(".baslik", { y: 40, opacity: 0, duration: 0.8, ease: "power2.out" });
  }
</script>
```

- `gsap.from` başlığı 40px aşağıdan ve opaklık 0'dan başlatıp CSS'teki son haline getiriyor. Sayfa yüklenince bir kez oynar, ScrollTrigger kullanılmadı.
- npm ile kullanıyorsan `import { gsap } from "gsap";` yaz, aynı satır çalışır.
- Hareketi azaltma ayarı (`prefers-reduced-motion`) açık olan kullanıcılarda animasyon oynamaz, başlık doğrudan görünür.
