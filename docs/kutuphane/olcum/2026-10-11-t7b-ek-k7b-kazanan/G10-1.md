Sayfa yüklenince bir kez çalışır, scroll'a bağlı değil:

```html
<h1 class="title">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  gsap.from(".title", {
    y: 40,          // 40px aşağıdan başlar, yerine kayar
    opacity: 0,     // 0 → 1
    duration: 0.8,
    ease: "power2.out",
  });
</script>
```

npm ile kullanacaksan `import { gsap } from "gsap";` ekle, gerisi aynı.

- `gsap.from` başlığı CSS'teki son haline getirir. Yani sayfa yüklendiğinde başlık zaten tam görünür ve yerinde durur.
- Script geç yüklenirse başlık önce bir an görünüp sonra kaybolabilir. Bunu yaşarsan CSS'e `.title { opacity: 0 }` ekle ve `gsap.from` yerine `gsap.fromTo(".title", { y: 40, opacity: 0 }, { y: 0, opacity: 1, duration: 0.8, ease: "power2.out" })` kullan.
- Hareketi azaltma tercihini (`prefers-reduced-motion`) dikkate almıyor. Bu gerekiyorsa animasyonu `gsap.matchMedia()` içine al.
