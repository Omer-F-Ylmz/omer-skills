```python
import bpy

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))  # size = kenar uzunluğu (m)
cube = bpy.context.active_object

mat = bpy.data.materials.new("Kirmizi")
mat.use_nodes = True
mat.node_tree.nodes["Principled BSDF"].inputs["Base Color"].default_value = (1, 0, 0, 1)
cube.data.materials.append(mat)
```

`use_nodes = True` ile Blender malzemeye varsayılan olarak "Principled BSDF" düğümünü ekler, kod yalnızca bu düğümün rengini değiştirir. Viewport'ta rengi görmek için Material Preview ya da Rendered moduna geçmen gerekir. Kodu Blender'da çalıştırmadım.
