Here's the plan for adding `--json` to `tools/olcum/kosucu.py`. I didn't write any code or change any files.

**Assumption (needs your OK):** with `--json`, each result row is printed to stdout as one JSON object per line. Each object has a `profil` field plus the 16 `BASLIK` columns, with the same names and order. The "başla", "bitti" and "->" lines move to stderr, so stdout carries only JSON. The TSV, `-init.json` and `.md` outputs stay exactly as they are. Without `--json`, nothing changes.

**What I found:**
- The only output point is `print(ad, s)` in `kos_profil`, at `kosucu.py:247`. The values are joined into a tab-separated string at `:243`, and that string is what gets printed.
- `bilesen.py` uses only `kos`, `jeton` and `CIKTI`. Changing the `kos_profil` signature doesn't affect it.
- Tests are in `tools/tests/test_olcum_kosucu.py`. `kos_profil` and `main` have no tests yet.
