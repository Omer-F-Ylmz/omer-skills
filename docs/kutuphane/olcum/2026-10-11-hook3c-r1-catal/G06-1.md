En güncel kararlı Playwright sürümü **v1.64.0**. 7 Ekim 2026'da yayımlandı, npm'de de `latest` etiketi bu sürümü gösteriyor.

**Trace viewer'ı CLI'dan açmak (Node.js):**
```bash
npx playwright show-trace path/to/trace.zip                 # yerel dosya
npx playwright show-trace https://example.com/trace.zip     # uzak URL
```
Trace dosyası yoksa önce testi trace açık çalıştırın: `npx playwright test --trace on`

Diğer dillerde aynı `show-trace` komutu kullanılır:
- **Python:** `playwright show-trace trace.zip`
- **.NET:** `pwsh bin/Debug/netX/playwright.ps1 show-trace trace.zip`
- **Java:** `mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI -D exec.args="show-trace trace.zip"`

Kurulum yapmadan açmak isterseniz dosyayı https://trace.playwright.dev sitesine sürükleyip bırakabilirsiniz.
