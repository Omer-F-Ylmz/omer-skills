Sayfa yüklenince bir kez çalışır, scroll'a bağlı değildir:

```html
<h1 class="baslik">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  if (!matchMedia('(prefers-reduced-motion: reduce)').matches) {
    gsap.from('.baslik', { y: 40, autoAlpha: 0, duration: 0.8, ease: 'power2.out' });
  }
</script>
```

npm ile kurduysan `import { gsap } from 'gsap';` satırını ekle, aynı `gsap.from` çağrısı çalışır.

- `gsap.from` başlığı 40px aşağıdan ve opaklık 0'dan başlatır, CSS'teki son haline getirir.
- `autoAlpha` opaklığı 0→1 yapar. Opaklık 0'dayken `visibility: hidden` da uygular.
- İşletim sisteminde "hareketi azalt" açık olan kullanıcılarda animasyon çalışmaz, başlık doğrudan görünür.
- Bunu test etmedim, kod bir taslak.
- Script geç yüklenirse başlık önce görünüp sonra kaybolabilir. Bunu yaşarsan h1'e CSS'te `visibility: hidden` ver. `autoAlpha` animasyon başlayınca onu kaldırır.
