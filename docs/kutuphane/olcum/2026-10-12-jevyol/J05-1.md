```python
a = [1, 2, 3]

# 1) Yerinde çevirme (listeyi değiştirir, None döndürür)
a.reverse()          # a -> [3, 2, 1]

# 2) Dilimleme (yeni bir liste döndürür, orijinal liste değişmez)
b = a[::-1]
```

Orijinal listeyi değiştirmek istemiyorsanız `[::-1]` kullanın. Liste üzerinde yalnızca tersten dolaşmanız gerekiyorsa `reversed(a)` kopya oluşturmadan bir iteratör verir.
