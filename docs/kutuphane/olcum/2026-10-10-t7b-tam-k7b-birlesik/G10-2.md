Aşağıdaki kod başlığı yüklenince bir kez oynatır, scroll'a bağlı değildir:

```html
<h1 class="hero-title">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)", () => {
    gsap.from(".hero-title", {
      y: 40,          // 40px aşağıdan başlar
      autoAlpha: 0,   // opacity 0 → 1
      duration: 0.8,
      ease: "power2.out",
    });
  });
</script>
```

npm ile kurduysan `import gsap from "gsap";` satırı yeterli. Kodun geri kalanı aynı kalır.

- **`autoAlpha`:** düz `opacity` gibi 0'dan 1'e çıkar. Ek olarak animasyon başlamadan önce başlığın bir anlığına tam görünüp kaybolmasını engeller.
- **`prefers-reduced-motion`:** cihazında "hareketi azalt" ayarı açık olan kullanıcıda animasyon çalışmaz ve başlık doğrudan görünür. Bunu istemiyorsan `matchMedia` sarmalayıcısını kaldır.
