```python
import bpy

# 2 m kenarlı küp (size = kenar uzunluğu)
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

# Kırmızı Principled BSDF malzeme
mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True
bsdf = mat.node_tree.nodes["Principled BSDF"]
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)

cube.data.materials.append(mat)
```

`use_nodes = True` ile yeni malzemede varsayılan olarak bir "Principled BSDF" düğümü oluşur. Sonra bu düğümün Base Color değerini kırmızıya ayarlıyoruz. Kodu Blender'ın Scripting sekmesinde çalıştırın. Sonucu Material Preview ya da Rendered görünümünde görürsünüz.
