# Güvenlik incelemesi (en ağırdan en hafife)

### 1. KRİTİK: SQL injection
```js
db.query("SELECT * FROM u WHERE id="+req.query.id);
```
- `?id=1 OR 1=1` isteği tablodaki bütün satırları döndürür.
- `?id=0 UNION SELECT ...` ile başka tablolardan da veri çekilebilir.
- Sürücüde `multipleStatements` açıksa `?id=1;DROP TABLE u` tabloyu siler.

**Düzeltme:** sorguyu parametreli yazın ve tipi doğrulayın.
```js
const id = Number.parseInt(req.query.id, 10);
if (!Number.isInteger(id)) return res.sendStatus(400);
db.query("SELECT ad, email FROM u WHERE id = ?", [id]); // pg kullanıyorsanız: $1
```

### 2. YÜKSEK: Path traversal (sunucudaki herhangi bir dosya okunabilir)
```js
const p='/data/'+req.query.ad; res.sendFile(p);
```
- `?ad=../etc/passwd` isteği `/data/../etc/passwd` yolunu açar.
- Mutlak yol verildiğinde `sendFile` `..` kontrolü yapmaz. Saldırgan `.env` dosyalarını, SSH anahtarlarını ve kaynak kodu okuyabilir.
- `?ad[]=x` gönderilirse değer string yerine dizi olarak gelir, bu da öngörülemeyen yollara yol açar.

**Düzeltme:** `root` seçeneği `..` içeren yolları 403 ile reddeder ve varsayılan olarak `.env` gibi gizli dosyaları sunmaz.
```js
app.get('/dosya', (req, res) => {
  const ad = req.query.ad;
  if (typeof ad !== 'string') return res.sendStatus(400);
  res.sendFile(ad, { root: '/data' }, err => err && res.sendStatus(err.status || 404));
});
```

### 3. ORTA: Fazla veri dönüyor
`SELECT *` sorgusu parola hash'i ve token gibi sütunları da getirir. Sonuç istemciye gönderiliyorsa bu bilgiler sızar. Yalnızca gereken sütunları seçin.

### 4. ORTA: Yetkilendirme yok (bu koddan kesin değil)
İki uç noktada da kimlik ya da sahiplik kontrolü görünmüyor. Kullanıcı `id` değerini değiştirerek başkasının kaydını okuyabilir (IDOR). Bunu üst katmandaki bir middleware yapıyor olabilir; kontrol edin.

### 5. DÜŞÜK: Hata yönetimi eksik
`db.query` için bir hata callback'i ya da `catch` yok. Express'in varsayılan hata sayfası, SQL hata metnini ve stack trace'i istemciye gösterebilir. Production'da `NODE_ENV=production` olmalı ve hatalar genel bir mesajla dönmeli.
