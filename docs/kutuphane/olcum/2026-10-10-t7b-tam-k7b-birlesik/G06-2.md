The latest stable Playwright version is **1.64.0**. It was published to npm on 2026-10-07 (from `npm view playwright`).

You open the trace viewer from the CLI with `show-trace`:

```bash
npx playwright show-trace path/to/trace.zip
# a remote trace also works:
npx playwright show-trace https://example.com/trace.zip
```

If you don't have a trace file yet, run your tests with `npx playwright test --trace on` and it will create one.
