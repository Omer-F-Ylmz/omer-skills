```python
import bpy

# size=2 → 2 m edge length
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True
bsdf = mat.node_tree.nodes["Principled BSDF"]
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)  # RGBA

cube.data.materials.append(mat)
```

Paste this into Blender's Scripting tab and click Run Script. I didn't run it in a live Blender session. `use_nodes = True` creates the "Principled BSDF" node automatically. If your Blender is set to a non-English language, that node may have a translated name and the `nodes["Principled BSDF"]` line will fail. In that case, use `next(n for n in mat.node_tree.nodes if n.type == 'BSDF_PRINCIPLED')` instead.
