```js
import { gsap } from "gsap";

gsap.matchMedia().add("(prefers-reduced-motion: no-preference)", () => {
  gsap.from("h1", { y: 40, opacity: 0, duration: 0.8, ease: "power2.out" });
});
```

- `gsap.from` başlığı 40px aşağıdan ve opacity 0'dan başlatıp CSS'teki son haline getirir. Animasyon sayfa açılır açılmaz bir kez çalışır, scroll'a bağlı değil.
- Hareketi azaltma ayarı açık olan kullanıcılarda animasyon çalışmaz, başlık doğrudan görünür.
- Başlık, JS yüklenmeden önce bir an görünüp sonra kayboluyorsa: CSS'e `h1 { visibility: hidden }` ekle ve `opacity: 0` yerine `autoAlpha: 0` kullan. Bu durumda hareketi azaltma ayarı açık olanlar için `visibility: visible` vermeyi de unutma.
