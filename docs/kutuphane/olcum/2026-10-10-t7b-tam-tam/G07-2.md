Blender 4.x/5.x'te çalışır. Text Editor'a yapıştırıp **Run Script** ile çalıştır:

```python
import bpy

# size kenar uzunluğu: 2 m
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True  # Blender 5'te zaten açık, satır zararsız
bsdf = next(n for n in mat.node_tree.nodes if n.type == 'BSDF_PRINCIPLED')
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)  # RGBA

cube.data.materials.append(mat)
```

`primitive_cube_add`'deki `size`, kenar uzunluğunu verir. Varsayılan da 2'dir, burada açıkça yazdım. Kodu Blender'da çalıştırmadım.
