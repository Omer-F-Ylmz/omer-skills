Sayfa yüklenince bir kez çalışır, scroll'a bağlı değildir:

```js
import { gsap } from "gsap";

gsap.matchMedia().add("(prefers-reduced-motion: no-preference)", () => {
  gsap.from("h1", { y: 40, autoAlpha: 0, duration: 0.8, ease: "power2.out" });
});
```

- **Hareket:** `from` başlığı 40px aşağıdan ve görünmez başlatır, sonra kendi yerine ve tam görünür hâline getirir. `autoAlpha` opaklığı 0→1 yapar; opaklık 0 iken öğeyi `visibility: hidden` ile de gizler.
- **Hareket azaltma:** Kullanıcı sisteminde hareket azaltmayı açtıysa animasyon çalışmaz ve başlık doğrudan görünür.
- **İlk kare titremesi:** JS yüklenmeden önce başlık bir anlığına görünebilir. Bunu önlemek için CSS'e `h1 { visibility: hidden; }` ekleyin. Bu durumda hareket azaltma açık olan kullanıcılar için `gsap.set("h1", { autoAlpha: 1 })` satırı da gerekir, yoksa başlık hiç görünmez.

Kodu çalıştırıp denemedim.
