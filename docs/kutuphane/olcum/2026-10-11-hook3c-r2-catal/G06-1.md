Playwright'ın en güncel kararlı sürümü **1.64.0**. npm'e 7 Ekim 2026'da yayımlandı ve `latest` etiketi bu sürümde. `next` etiketindeki 1.65.0-alpha kararlı değil.

**Trace viewer'ı CLI'dan açmak için:**

```bash
# Yerel dosya (trace.zip'in tam yolunu ver)
npx playwright show-trace path/to/trace.zip

# Uzak dosya, indirmeden açılır (ör. CI artefaktı)
npx playwright show-trace https://example.com/trace.zip
```

Elinde trace yoksa testleri `npx playwright test --trace on` ile çalıştırarak kaydedebilirsin. Sonra `npx playwright show-report` ile raporu açıp trace simgesine tıkla. CLI kullanmak istemezsen https://trace.playwright.dev adresine zip dosyasını sürükleyip bırakman yeterli. Dosya sadece tarayıcında işlenir, dışarı gönderilmez.

**Kaynaklar:**
- Sürüm: https://www.npmjs.com/package/playwright (`npm view playwright dist-tags` komutuyla doğrulandı)
- Trace viewer: https://playwright.dev/docs/trace-viewer
