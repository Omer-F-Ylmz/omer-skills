**En güncel kararlı sürüm: Playwright 1.64.0.** GitHub'da 2026-10-07 tarihinde yayımlandı; `npm view playwright version` da aynı sürümü döndürüyor.

**Trace viewer'ı CLI'dan açmak (Node):**
```bash
npx playwright show-trace path/to/trace.zip              # yerel dosya
npx playwright show-trace https://example.com/trace.zip  # uzak URL
npx playwright show-report                               # HTML raporu açar, testlerin trace'leri de buradan görülebilir
```
Diğer diller:
- Python: `playwright show-trace trace.zip`
- .NET: `pwsh bin/Debug/netX/playwright.ps1 show-trace trace.zip`
- Java: `mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI -D exec.args="show-trace trace.zip"`

Kurulum gerektirmeyen alternatif: https://trace.playwright.dev adresinde dosyayı sürükleyip bırakabilir ya da `?trace=<url>` parametresiyle açabilirsiniz (CORS kuralları geçerli olabilir).
