npm'deki en güncel kararlı sürüm **Playwright 1.64.0** (`latest` etiketi). Bunu bugün `npm view playwright dist-tags` ile doğruladım. 1.65 henüz yalnızca `next` (alpha) etiketinde.

**Trace viewer'ı CLI'dan açmak için:**

```bash
npx playwright show-trace path/to/trace.zip
```

- Uzak bir trace'i de açabilirsiniz: `npx playwright show-trace https://example.com/trace.zip`
- Playwright Test raporundan açmak için: `npx playwright show-report`, ardından ilgili testteki trace simgesine tıklayın.
- Kurulum gerektirmeyen seçenek: zip dosyasını https://trace.playwright.dev sayfasına sürükleyin.

Trace'i kaydetmek için ya `playwright.config` içinde `use: { trace: 'on-first-retry' }` ayarlayın ya da testi `npx playwright test --trace on` ile çalıştırın.

**Kaynaklar:**
- Sürüm: https://www.npmjs.com/package/playwright
- Sürüm notları: https://github.com/microsoft/playwright/releases
- Trace Viewer dokümanı: https://playwright.dev/docs/trace-viewer
