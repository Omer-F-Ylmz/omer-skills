```html
<h1 class="hero-title">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
    gsap.from(".hero-title", {
      y: 40,          // 40px aşağıdan başlar
      autoAlpha: 0,   // opaklık 0'dan 1'e gider, başta visibility: hidden
      duration: 0.8,
      ease: "power2.out",
    });
  }
</script>
```

`gsap.from` başlığı verilen değerlerden alıp CSS'teki asıl konumuna ve opaklığına getirir. Animasyon sayfa açılınca bir kez çalışır, scroll'a bağlı değildir. `autoAlpha` opaklıkla birlikte `visibility` değerini de değiştirir, böylece animasyon başlamadan başlık bir an görünüp kaybolmaz. Ekranda hareketi azaltma tercihini açan kullanıcılara animasyon gösterilmez, başlık doğrudan görünür.

Kodu tarayıcıda çalıştırıp denemedim. React kullanıyorsan aynı çağrıyı `useGSAP()` hook'unun içine koy.
