```js
import { gsap } from "gsap";

if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
  gsap.from("h1", { y: 40, opacity: 0, duration: 0.8, ease: "power2.out" });
}
```

`gsap.from` başlığı 40px aşağıdan ve opacity 0'dan başlatır, CSS'te tanımlı konumuna ve opacity 1'e getirir. Sayfa yüklenince bir kez çalışır, scroll'a bağlı değildir. Hareketi azalt (reduced motion) ayarı açık olan kullanıcılara animasyon oynatılmaz, başlık doğrudan görünür.

- Script geç yüklenirse başlık bir an görünüp sonra kaybolabilir. Bunu yaşarsan h1'e CSS'te `visibility: hidden` ver, `opacity: 0` yerine `autoAlpha: 0` kullan.
