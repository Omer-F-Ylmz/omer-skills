**`markitdown`** kullanılmalı. Bilgisayarında kurulu (pandoc kurulu değil). Belge departmanının katalogunda docx'i Markdown'a çeviren bir skill yok. `make-pdf` ters yönde, Markdown'dan PDF'e çeviriyor. `adobe-anydocx` ise Adobe'nin bulut servisine gidiyor, sözleşmeyi dışarıya göndermemek için onu atladım.

PowerShell:
```powershell
markitdown sozlesme.docx -o sozlesme.md
Select-String -Path sozlesme.md -Pattern '^#{1,6} ' | ForEach-Object { $_.Line }
```

Git Bash:
```bash
markitdown sozlesme.docx -o sozlesme.md && grep -E '^#{1,6} ' sozlesme.md
```

Başlıkları satır numarasıyla görmek istersen `grep -nE` kullan.

Dikkat: markitdown yalnızca Word'de "Başlık 1/2/…" stiliyle biçimlendirilmiş satırları `#` başlığa çevirir. Sözleşmede başlıklar sadece kalın yazılmışsa bu komut boş döner. O durumda maddeler `**MADDE 1 – ...**` biçiminde çıkar ve şununla bulunur:

```bash
grep -nE '^\*\*(MADDE|Madde) ' sozlesme.md
```
