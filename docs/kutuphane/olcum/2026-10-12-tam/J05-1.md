```python
a = [1, 2, 3]

# 1) Listeyi yerinde ters çevirir, geriye None döner
a.reverse()

# 2) Dilimleme: yeni, ters çevrilmiş bir liste döner, a'ya dokunmaz
b = a[::-1]
```

Orijinal listeyi değiştirmek istiyorsan `reverse()`'u, yeni bir liste istiyorsan `[::-1]`'i kullan. Listeyi yalnızca tersten dolaşacaksan `reversed(a)` kopya oluşturmaz.
