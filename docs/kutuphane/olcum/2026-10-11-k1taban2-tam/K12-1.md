Bu iş için **`make-pdf`** skill'ini seçtim. Belge departmanı markdown'dan PDF üretimi için bunu öneriyor. Binary kurulu ve hazır: `~/.claude/skills/gstack/make-pdf/dist/pdf`. Bu makinede pandas yok, o yüzden aşağıdaki script yalnızca standart kütüphaneyi kullanıyor. Grafik için ayrı bir kütüphane gerekmiyor, make-pdf mermaid bloklarını vektör grafik olarak çiziyor.

**Varsayım:** CSV'nin sütunları `tarih,urun,adet,tutar`. Sende farklıysa script'teki 4 sütun adını değiştirmen yeterli.

### 1. CSV'den markdown üret: `rapor.py`
```python
import csv, sys
from collections import defaultdict

src, ay = sys.argv[1], sys.argv[2]           # python rapor.py satis.csv "Eylül 2026"
gun, urun = defaultdict(float), defaultdict(float)
adet = 0
with open(src, encoding="utf-8-sig", newline="") as f:
    for r in csv.DictReader(f):
        t = float(r["tutar"].replace(",", "."))
        gun[r["tarih"][-2:]] += t
        urun[r["urun"]] += t
        adet += int(r["adet"])

top = sum(gun.values())
g = sorted(gun)
ilk5 = sorted(urun.items(), key=lambda x: -x[1])[:5]
md = [f"# Satış Raporu — {ay}", "",
      f"**Ciro:** {top:,.2f} TL · **Adet:** {adet} · **Günlük ort.:** {top/len(g):,.2f} TL", "",
      '```mermaid title="Günlük ciro"', "xychart-beta",
      f"  x-axis [{', '.join(g)}]", f"  bar [{', '.join(f'{gun[d]:.0f}' for d in g)}]", "```", "",
      "| Ürün | Ciro (TL) | Pay |", "|---|---:|---:|"]
md += [f"| {u} | {v:,.2f} | %{v/top*100:.1f} |" for u, v in ilk5]
open("rapor.md", "w", encoding="utf-8").write("\n".join(md))
```

### 2. PDF'i tek sayfa olarak üret
```bash
P=~/.claude/skills/gstack/make-pdf/dist/pdf
python rapor.py satis.csv "Eylül 2026"
$P preview rapor.md        # önce tarayıcıda kontrol et
$P generate --page-size a4 --margins 0.75in --no-chapter-breaks --no-confidential rapor.md rapor.pdf
```

### 3. Tek sayfaya sığdığını doğrula
`pdfinfo rapor.pdf | grep Pages` komutu `1` döndürmeli. Taşıyorsa önce `--margins 0.5in` dene, yine sığmazsa tabloyu 3 ürüne indir.

**Notlar:**
- Script'i senin CSV'n üzerinde çalıştırmadım, PDF de üretmedim. Henüz test edilmedi.
- make-pdf'in içindeki mermaid sürümünün `xychart-beta`'yı desteklediğini doğrulamadım. Grafik yerine kırmızı bir hata kutusu çıkarsa mermaid bloğunu sil, günlük ciroyu tabloya çevir.
- Sayılardaki binlik ayırıcı İngilizce biçimde (`1,234.56`). Türkçe biçim istersen söyle.
