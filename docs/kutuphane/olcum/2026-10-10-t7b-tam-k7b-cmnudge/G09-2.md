# Güvenlik incelemesi (en ciddiden aza)

**1. Kritik: SQL injection** (`db.query`)
`req.query.id` doğrudan SQL metnine ekleniyor.
- `?id=1 OR 1=1` isteği tüm kullanıcıları döndürür.
- `?id=0 UNION SELECT ...` başka tablolardan veri çeker.
- Sürücü çoklu sorguya izin veriyorsa `?id=1; DROP TABLE u` tabloyu siler.

Çözüm parametreli sorgudur:
```js
const id = Number.parseInt(req.query.id, 10);
if (!Number.isInteger(id)) return res.sendStatus(400);
db.query('SELECT * FROM u WHERE id = ?', [id]); // pg kullanıyorsanız: $1
```

**2. Yüksek: Path traversal** (`/dosya`)
`'/data/' + req.query.ad` ile yol, kullanıcı girdisiyle hiç kontrol edilmeden kuruluyor. Amaç `?ad=../etc/passwd` gibi bir istekle `/data` dışına çıkmak.
- Güncel Express'te `send` modülü `..` içeren yolları 403 ile reddediyor. Bu yüzden bugün doğrudan sömürülemiyor olabilir.
- Ama bu koruma sizin kodunuzdan değil, kütüphanenin iç davranışından geliyor. Express sürümü değişirse ya da kod başka bir dosya okuma fonksiyonuna taşınırsa açık hemen ortaya çıkar.

Çözüm, `sendFile`'ın belgelenmiş `root` seçeneğini kullanmaktır:
```js
app.get('/dosya', (req, res) => {
  if (typeof req.query.ad !== 'string') return res.sendStatus(400);
  res.sendFile(req.query.ad, { root: '/data' }, err => err && res.sendStatus(404));
});
```

**3. Orta: Yetkilendirme yok** (`/dosya`)
`/data` altındaki her dosya, giriş yapmamış olanlar dahil herkese açık. Klasörde kullanıcıya özel dosya varsa bu bir veri sızıntısıdır. Dosyanın isteyen kullanıcıya ait olup olmadığı kontrol edilmeli.

**4. Düşük: Hata yönetimi ve bilgi sızıntısı**
- `sendFile` callback'siz çağrılıyor. Dosya yoksa hata Express'in varsayılan hata işleyicisine gidiyor ve `NODE_ENV` production değilse yanıtta stack trace ile sunucudaki tam dosya yolu görünüyor.
- `db.query` için de hata yönetimi yok.

**5. Bilgi notu: `SELECT *`**
Sonuç istemciye dönüyorsa parola hash'i gibi alanlar da gidebilir. Sadece gereken kolonları seçin.

Snippet'te sorgu sonucunun nasıl kullanıldığı ve kimlik doğrulama middleware'i görünmüyor. 3. ve 5. maddelerin şiddeti bunlara göre değişir.
