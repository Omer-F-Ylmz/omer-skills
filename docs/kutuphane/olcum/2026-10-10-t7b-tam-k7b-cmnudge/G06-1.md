**Güncel kararlı sürüm: Playwright 1.64.0** (npm `latest` etiketi, 7 Ekim 2026'da yayımlandı). `next` etiketinde 1.65.0 alpha var, ama o kararlı değil.

**Trace viewer'ı CLI'dan açmak:**

```bash
npx playwright show-trace path/to/trace.zip              # yerel dosya (tam yol ver)
npx playwright show-trace https://example.com/trace.zip  # uzak URL, örn. CI çıktısı
```

Trace kaydetmek için testleri `npx playwright test --trace on` ile çalıştır. Kurulum gerektirmeyen seçenek de var: zip dosyasını https://trace.playwright.dev sitesine sürükleyip bırakabilirsin. Dosya tarayıcıda açılır, dışarıya gönderilmez.

**Kaynaklar:**
- Sürüm: https://www.npmjs.com/package/playwright (`npm view playwright dist-tags` ile doğrulandı)
- Trace viewer: https://playwright.dev/docs/trace-viewer
