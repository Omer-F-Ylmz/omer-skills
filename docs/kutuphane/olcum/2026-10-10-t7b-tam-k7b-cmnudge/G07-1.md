```python
import bpy

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True
bsdf = mat.node_tree.nodes["Principled BSDF"]
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)  # RGBA

cube.data.materials.append(mat)
```

`size=2`, küpün her kenarını 2 m yapar. Kodu Blender'ın Scripting sekmesinde, Object Mode'dayken çalıştır. Ben Blender'da çalıştırıp test etmedim.

Blender 5.0'dan itibaren `use_nodes` artık gerekmiyor ve uyarı verebilir. Daha eski sürümlerde bu satır gerekli. Uyarı alırsan satırı silebilirsin.
