## DESIGN.md

```markdown
# 1. Stil adı
Kavurma Defteri — sıcak editoryal, zanaat künyesi

# 2. Token'lar
- ölçü-birimi: 8px grid (8/16/24/32/48/64/96)
- satır-uzunluğu: 60ch
- köşe: 6px
- zemin: düz krema + tek radial ışık, grain yok
- kadran: deneysellik 2 · hareket 2 · yoğunluk 2

# 3. Renk
- kavrulmuş-çekirdek #3B2416 — metin, koyu yüzey
- süt-kreması #F4EDE3 — zemin
- bakır-cezve #B5562B — tek vurgu, CTA
- kakule #5E6B4E — damga/etiket
- duman #6B5F54 — ikincil metin

# 4. Tipografi
Gloock 400 (display) + Instrument Sans 400/600 (gövde).
Ölçek: 14 / 16 / 20 / 32 / clamp(40→88). h1 -0.03em, gövde line-height 1.7.

# 5. Hareket
- Yükleme: damga, eylem ve künye 600ms cubic-bezier(.22,1,.36,1) ile opacity + translateY(16px), 80ms arayla. Kütüphane yok, CSS keyframes yetiyor. h1 animasyonsuz (LCP korunur).
- Hover: buton translateY(-1px), 200ms, aynı easing.
- prefers-reduced-motion: reduce olunca hepsi kapalı.

# 6. YASAK LİSTESİ
mor degrade · aşırı glow · eşit üçlü kart · her yerde ikon · merkezli tek kolon ·
lorem ipsum · 8px üstü yuvarlatma · gereksiz gölge · çekirdek emoji/clipart · stok latte-art hissi
```
