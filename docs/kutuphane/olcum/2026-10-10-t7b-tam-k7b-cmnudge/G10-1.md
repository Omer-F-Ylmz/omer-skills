```html
<h1 class="hero-title">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
    gsap.from(".hero-title", {
      y: 40,          // 40px aşağıdan başlar, kendi yerine gelir
      opacity: 0,     // 0'dan CSS'teki değere (1) çıkar
      duration: 0.8,
      ease: "power2.out",
    });
  }
</script>
```

- Animasyon sayfa yüklenince bir kez çalışır. ScrollTrigger kullanmadım, scroll'a bağlı değil.
- `prefers-reduced-motion` açık olan kullanıcılarda animasyon atlanır ve başlık doğrudan görünür.
- Script başlıktan sonra yüklenirse başlık bir an görünüp kaybolabilir. Bu titreme olursa h1'e CSS ile `opacity:0` verin, kodda da `gsap.from` yerine `gsap.fromTo(".hero-title", {y:40, opacity:0}, {y:0, opacity:1, duration:0.8, ease:"power2.out"})` kullanın. Bunu yaparsanız reduced-motion durumunda opaklığı 1'e çeken bir CSS kuralı da gerekir.
