Yükleme anında bir kere oynayan animasyon. ScrollTrigger kullanılmıyor:

```html
<h1 class="baslik">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
    gsap.from(".baslik", {
      y: 40,          // 40px aşağıdan başlar, kendi yerine kayar
      autoAlpha: 0,   // opaklık 0 → 1 (görünürlüğü de yönetir)
      duration: 0.8,
      ease: "power2.out",
    });
  }
</script>
```

- **npm ile kullanmak için:** `npm i gsap` kurup `import { gsap } from "gsap";` ile içe aktarın. Animasyon kodu aynı kalıyor.
- **Hareketi azaltma tercihi:** Sistemde "hareketi azalt" açıksa animasyon oynamaz, başlık doğrudan görünür.
- **Sayfa açılırken titreme:** Başlık bir an görünüp kaybolursa h1'e CSS'te `visibility: hidden` verin. `autoAlpha` animasyon başlarken görünür yapar. Bu durumda "hareketi azalt" dalına da `gsap.set(".baslik", { autoAlpha: 1 })` eklemeniz gerekir, yoksa başlık gizli kalır.

Kodu tarayıcıda çalıştırmadım. Bu klasörde bir proje olmadığı için dosyaya da yazmadım.
