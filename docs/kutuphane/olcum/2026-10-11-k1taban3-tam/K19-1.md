I wrote a 5-slot inventory skeleton using the `build-game-inventory` skill. All 4 tests pass, but I haven't tried the drag-and-drop in a browser yet.

The working folder was empty, so I couldn't find your game code. These are standalone files, not wired into your game:

- `inventory.js` holds the item definitions and the slot state. Adding to a full inventory returns `false`. Moving two items swaps them in one step, so an item never disappears.
- `inventory-ui.js` builds the bar that sits on top of the Three.js canvas. Mouse drag-and-drop works, and so does click/Enter/Space to pick a slot and then click the target slot (for keyboard and touch).
- `inventory.css` has minimal styling for the slot bar.
- `inventory.test.mjs` holds the 4 tests: full inventory, swapping without losing items, invalid moves changing nothing, and unknown items being rejected.

To hook it into your game:
```js
const inventory = createInventory();
mountInventory(inventory, document.getElementById('inventory'));
// on pickup collision: remove the mesh only if the add succeeded
if (inventory.add(mesh.userData.itemId)) scene.remove(mesh);
```
