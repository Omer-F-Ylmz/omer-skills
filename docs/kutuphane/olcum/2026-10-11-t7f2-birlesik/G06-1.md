**En güncel kararlı sürüm: Playwright 1.64.0.** 7 Ekim 2026'da yayımlandı. npm `latest` etiketi ve GitHub "latest release" aynı sürümü gösteriyor.

**Trace viewer'ı CLI'dan açmak için:**
```bash
npx playwright show-trace path/to/trace.zip
# veya uzaktaki bir trace dosyası:
npx playwright show-trace https://example.com/trace.zip
```
Trace dosyasını CLI kullanmadan https://trace.playwright.dev adresine sürükleyip bırakarak da açabilirsin.
