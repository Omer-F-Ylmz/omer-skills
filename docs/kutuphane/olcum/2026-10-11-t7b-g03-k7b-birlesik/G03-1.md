```md
# 1. Stil adı
Kavurmahane Editoryal — gazete sayfası ritmi, sıcak kâğıt zemin

# 2. Token'lar
ölçü-birimi: 8px (8/16/24/32/48/64/96)

köşe: 2px
zemin: düz çiğ-krem, gradient/grain yok

# 3. Renk
espresso #1E1410 · kavrulmuş-bakır #A3461F · çiğ-krem #F4EDE4 · sütlü-köpük #FBF7F2 · telve #5E4A3F

Fraunces 500 (display) + Instrument Sans 400/600 (gövde)
ölçek: 88 / 40 / 18 / 16 / 12px; başlık -0.03em, gövde 1.7

# 5. Hareket
yükleme: metin blokları 16px yukarıdan opacity+transform, 700ms, cubic-bezier(.22,1,.36,1), 80ms stagger, CSS (kütüphane yok)
hover: buton yalnız renk değişimi, active'de 1px translate
prefers-reduced-motion: tümü kapalı

# 6. YASAK LİSTESİ
mor degrade · aşırı glow · üçlü eşit kart · her yerde ikon · merkezli tek kolon · lorem ipsum · aşırı yuvarlatma · gereksiz shadow · emoji · blur kart · h1+p+2 buton hero
```

Bu taslakta kontrast oranları şöyle: espresso/krem yaklaşık 16:1, telve/krem 7.3:1, krem/bakır 5.2:1. Hepsi AA seviyesini geçiyor.
