Varsayılan `size=2` zaten 2 m kenar verdiği için ölçek ayarı gerekmiyor.

```python
import bpy

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
kup = bpy.context.active_object

mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True  # Blender 5.x'te zaten açık, satır zararsız
bsdf = mat.node_tree.nodes["Principled BSDF"]
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)

kup.data.materials.append(mat)
```

Kodu Scripting sekmesinde çalıştırın. Kırmızı rengi görmek için görünümü Material Preview ya da Rendered moda alın. Solid modda da kırmızı görünmesi isterseniz şu satırı ekleyin: `mat.diffuse_color = (1, 0, 0, 1)`
