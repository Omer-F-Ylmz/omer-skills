Playwright'ın en güncel kararlı sürümü **1.64.0**. Bunu npm'deki `latest` etiketinden aldım. Bu etiket kararlı sürümü gösterir; beta ve canary sürümleri ayrı etiketlerde durur.

Trace viewer'ı CLI'dan açmak için:

```bash
npx playwright show-trace path/to/trace.zip              # yerel dosya
npx playwright show-trace https://example.com/trace.zip  # uzaktaki dosya (CI'dan indirmeden açar)
```

Diğer diller:
- Python: `playwright show-trace trace.zip`
- .NET: `pwsh bin/Debug/netX/playwright.ps1 show-trace trace.zip`

Trace kaydetmek için testleri `npx playwright test --trace on` ile koşturun. Sonra `npx playwright show-report` ile HTML raporunu açıp trace simgesine tıklayın.

Kurulum gerektirmeyen yol: https://trace.playwright.dev adresine zip'i sürükleyip bırakın. Dosya tarayıcıda işlenir, dışarı gönderilmez. Uzaktaki bir dosyayı `?trace=<url>` parametresiyle de açabilirsiniz; bu durumda CORS engel olabilir.

**Kaynaklar:**
- Sürüm: https://registry.npmjs.org/playwright/latest
- Trace viewer belgesi: https://playwright.dev/docs/trace-viewer (kaynak dosyası: https://github.com/microsoft/playwright/blob/main/docs/src/trace-viewer.md)
