```python
a = [1, 2, 3, 4]

# 1) Dilimleme: yeni bir ters liste döndürür, orijinal liste değişmez
b = a[::-1]      # [4, 3, 2, 1]

# 2) reverse(): listeyi yerinde ters çevirir ve None döndürür
a.reverse()      # a artık [4, 3, 2, 1]
```

Orijinal listeyi korumak istiyorsan `[::-1]` kullan, listeyi yerinde değiştirmek istiyorsan `reverse()` kullan.
