```html
<h1>Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  gsap.matchMedia().add("(prefers-reduced-motion: no-preference)", () => {
    gsap.from("h1", { y: 40, opacity: 0, duration: 0.8, ease: "power2.out" });
  });
</script>
```

`gsap.from` başlığı 40px aşağıdan ve opaklık 0'dan başlatıp CSS'teki asıl hâline getiriyor. Sayfa yüklenince bir kez çalışıyor, ScrollTrigger kullanılmadı. Hareket azaltmayı seçen kullanıcılarda animasyon çalışmıyor ve başlık direkt görünüyor.

Kodu tarayıcıda çalıştırmadım. Script geç yüklenirse başlık animasyondan önce bir an görünebilir. Böyle olursa `h1 { visibility: hidden }` ekleyip `opacity` yerine `autoAlpha: 0` kullanabilirsin.
