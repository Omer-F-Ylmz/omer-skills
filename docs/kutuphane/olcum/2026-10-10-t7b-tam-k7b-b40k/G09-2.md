Bu iki satırda iki gerçek açık var. Asıl risk SQL injection; dosya okuma kısmını Express'in kendi kontrolü kısmen koruyor.

**1. Kritik: SQL Injection (`db.query`)**
`id` doğrudan sorguya ekleniyor.
- `?id=1 OR 1=1` tüm kullanıcıları döndürür.
- `?id=0 UNION SELECT ...` başka tablolardan veri çeker.
- Sürücü birden fazla sorguya izin veriyorsa `?id=1; DROP TABLE u` tabloyu siler.

Çözüm parametreli sorgu:
```js
db.query('SELECT * FROM u WHERE id = ?', [req.query.id]);   // pg: $1
```

**2. Yüksek: Path traversal ve yetkisiz dosya erişimi (`/dosya`)**
`'/data/' + ad` ifadesinin `/data` dışına çıkmasını kodda hiçbir şey engellemiyor.
- Saldırı: `?ad=../etc/passwd` veya `?ad=../app/.env`.
- Express'in kullandığı `send` modülü, `root` verilmediğinde yolda `..` görürse 403 döndürür. Bu yüzden bu saldırı bugün muhtemelen engelleniyor. Ama güvenlik tamamen kütüphanenin bu davranışına dayanıyor.
- Ayrıca kimlik doğrulama yok. Herkes `/data` altındaki her dosyayı okuyabilir, örneğin başka kullanıcıların dosyalarını (IDOR).
- `?ad[]=x` gibi bir istekte `ad` string yerine dizi olarak gelir. Bunun için tip kontrolü yok.

Çözüm:
```js
app.get('/dosya', requireAuth, (req, res) => {
  const ad = req.query.ad;
  if (typeof ad !== 'string') return res.sendStatus(400);
  res.sendFile(ad, { root: '/data', dotfiles: 'deny' },
    err => err && !res.headersSent && res.sendStatus(err.status || 404));
});
```
`root` seçeneği verilince `send` yolu normalize eder ve `/data` dışına çıkılmasına izin vermez. `requireAuth` için uygulamanızdaki mevcut auth middleware'ini kullanın. Dosyalar kullanıcıya özelse ayrıca sahiplik kontrolü gerekir.

**3. Düşük: Hata sızıntısı**
`sendFile` için hata callback'i yok. Dosya bulunamadığında hata varsayılan handler'a gidiyor. `NODE_ENV` production değilse yanıtta stack trace ve sunucudaki dosya yolları görünüyor. Yukarıdaki callback bunu da kapatıyor.

**4. Düşük: Gereğinden fazla veri**
`SELECT *` şifre hash'i gibi hassas kolonları da döndürebilir. Sadece gereken kolonları seçin.

Bu inceleme kod okumaya dayanıyor; düzeltmeleri çalıştırıp test etmedim.
