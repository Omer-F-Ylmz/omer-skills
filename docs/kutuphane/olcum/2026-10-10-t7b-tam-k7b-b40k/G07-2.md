```python
import bpy

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

mat = bpy.data.materials.new("Kirmizi")
mat.use_nodes = True
mat.node_tree.nodes["Principled BSDF"].inputs["Base Color"].default_value = (1, 0, 0, 1)

cube.data.materials.append(mat)
```

`size=2` her kenarı 2 m olan bir küp oluşturur. `use_nodes = True` ile malzemeye varsayılan "Principled BSDF" düğümü otomatik olarak eklenir.
