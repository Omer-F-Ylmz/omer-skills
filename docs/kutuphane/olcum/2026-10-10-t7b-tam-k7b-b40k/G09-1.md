# Güvenlik incelemesi (en ciddiden en hafife)

**1. Kritik: SQL injection**
```js
db.query("SELECT * FROM u WHERE id="+req.query.id);
```
`req.query.id` sorguya olduğu gibi ekleniyor. Saldırgan sorgunun yapısını değiştirebilir:
- `?id=1 OR 1=1` tüm kullanıcıları döndürür.
- `?id=0 UNION SELECT ...` başka tablolardaki verileri çeker.
- `?id=1; DROP TABLE u` ile tablo silinebilir. Bu, sürücü birden fazla ifadeye izin veriyorsa çalışır: pg'de parametresiz sorgular, mysql'de `multipleStatements: true`.

Düzeltme: parametreli sorgu kullanın ve id'nin sayı olduğunu doğrulayın.
```js
const id = Number.parseInt(req.query.id, 10);
if (!Number.isInteger(id)) return res.sendStatus(400);
db.query("SELECT * FROM u WHERE id = ?", [id]);   // pg: $1
```

**2. Orta: Path traversal deseni (şu an kütüphane engelliyor)**
```js
const p='/data/'+req.query.ad; res.sendFile(p);
```
Dosya yolu kullanıcı girdisinden oluşuyor. `?ad=../etc/passwd` denemesini Express'in kullandığı `send` modülü 403 ile reddediyor, çünkü `root` verilmediğinde `..` içeren yolları engelliyor. Yani doğrudan sömürülemiyor, ama savunma tamamen kütüphanenin bu davranışına bağlı. Açık kalan riskler:
- `/data` altındaki bir symlink dışarıyı gösteriyorsa takip edilir.
- Yetki kontrolü yok, `/data` altındaki her dosya herkese açık (IDOR).

Düzeltme:
```js
const ad = req.query.ad;
if (typeof ad !== 'string') return res.sendStatus(400);
res.sendFile(ad, { root: '/data', dotfiles: 'deny' }, err => err && res.sendStatus(404));
```

**3. Düşük: Hata mesajında bilgi sızıntısı**
`sendFile` için callback yok, bu yüzden hata `next(err)` ile varsayılan hata işleyicisine gider. Production dışı ortamda stack trace ve `/data/...` gibi tam yollar istemciye gösterilir. Yukarıdaki callback bunu da kapatıyor.

**4. Düşük: `SELECT *`**
Sonuç istemciye dönüyorsa parola hash'i gibi hassas kolonlar da gider. Gerekli kolonları tek tek seçin.

Bu inceleme kod çalıştırılmadan, sadece okunarak yapıldı. Kimlik doğrulama middleware'inin olup olmadığı bu iki satırdan anlaşılmıyor. Yoksa iki endpoint de herkese açık demektir.
