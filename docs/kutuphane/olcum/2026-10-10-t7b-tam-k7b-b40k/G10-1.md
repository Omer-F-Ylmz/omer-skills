Sayfa yüklenince bir kez çalışır, ScrollTrigger kullanılmıyor:

```html
<style>
  /* JS çalışmadan önce başlığın bir an görünüp kaybolmasını önler */
  .hero-title { visibility: hidden; }
</style>

<h1 class="hero-title">Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches;

  gsap.fromTo(".hero-title",
    { y: reduce ? 0 : 40, autoAlpha: 0 },
    { y: 0, autoAlpha: 1, duration: 0.8, ease: "power2.out" }
  );
</script>
```

- **`autoAlpha`:** Opaklığı 0'dan 1'e çıkarır ve `visibility` değerini kendisi yönetir. CSS'teki `hidden` bu yüzden sorun çıkarmaz.
- **Hareket azaltma tercihi:** Kullanıcı sistemde hareket azaltmayı açtıysa 40px kayma yapılmaz, başlık yalnızca belirerek gelir.
- **npm ile kullanım:** `import { gsap } from "gsap";` ekle, kodun geri kalanı aynı kalır.

Bunu sadece kod olarak verdim, tarayıcıda çalıştırıp denemedim.
