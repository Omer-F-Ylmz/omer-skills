**Kök neden:** async işlemin sonucu senkron olarak bekleniyor (sync-over-async). `o.Result` çağrısı thread'i bloke ediyor. Klasik ASP.NET, WPF/WinForms ve Blazor Server'da bir SynchronizationContext var. `FirstOrDefaultAsync` bittiğinde devamını o context'e göndermek istiyor, ama o thread `.Result` yüzünden bekliyor. İkisi birbirini beklediği için deadlock oluşuyor. Sorgu bazen senkron tamamlandığı için hata "zaman zaman" çıkıyor. ASP.NET Core'da SynchronizationContext yok, orada aynı kod thread pool starvation'a yol açar. Ayrıca metot `async` işaretli ama içinde `await` yok, derleyici bunun için CS1998 uyarısı verir.

**Düzeltme:**
```csharp
public async Task<Order?> Get(int id)
{
    return await _db.Orders.FirstOrDefaultAsync(x => x.Id == id);
}
```

Bu metodu çağıran kodu da kontrol et: zincirin yukarısında `.Result`, `.Wait()` veya `GetAwaiter().GetResult()` kaldıysa deadlock orada da oluşur. Bunların hepsini `await` ile değiştirmek gerekiyor.

İstenmediği için `CancellationToken` eklemedim. İsteğin iptal edilebilmesi gerekiyorsa `Get(int id, CancellationToken ct)` imzasıyla `FirstOrDefaultAsync(x => x.Id == id, ct)` kullanabilirsin.
