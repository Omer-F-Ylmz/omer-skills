İki ayrı kök neden var. İkisini de önce kırmızı testle kanıtladım, düzelttikten sonra 3 test geçti.

**1. Değiştirilebilir varsayılan argüman (`liste=[]`).** Python varsayılan değeri fonksiyon tanımlanırken bir kez üretir. Bu yüzden bütün çağrılar ve testler aynı listeyi paylaşıyor. Kanıt: `ekle(1)` sonrası `ekle(2)` `[2]` yerine `[1, 2]` döndü. Düzeltme:
```python
def ekle(x, liste=None):
    if liste is None:
        liste = []
    liste.append(x)
    return liste
```

**2. Geç bağlanan kapanış (late binding).** Lambda `i` değerini oluşturulduğu anda değil, çağrıldığı anda okuyor. Döngü bittiğinde `i == 2` olduğu için hepsi aynı değeri basıyor. Kanıt: çıktı `['2','2','2']` çıktı, beklenen `['0','1','2']` idi. Düzeltme:
```python
dugmeler = [lambda i=i: print(i) for i in range(3)]
```

Dosyalar: `kod.py` (düzeltilmiş kod), `test_kod.py` (3 test: çağrılar arası bağımsızlık, verilen listenin kullanılması, her düğmenin kendi değerini basması).

Varsayım: "tek tek doğru, birlikte karışıyor" şikâyetini ilk neden açıklıyor, ikinci neden ayrı bir hata. Gerçek proje kodun bu dosyadan farklıysa orada da `=[]` ve döngü içi lambda kalıplarını aramak gerekir.
