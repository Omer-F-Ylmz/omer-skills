**1. Değiştirilebilir varsayılan argüman (`liste=[]`)**
- Varsayılan liste, fonksiyon tanımlanırken bir kez üretilir. `liste` verilmeyen her çağrı aynı nesneyi kullanır, bu yüzden testler birbirine karışıyor.
- Kanıt: `ekle_bug(1) is ekle_bug(2)` doğru çıktı. Üç çağrıdan sonra `ekle_bug.__defaults__[0] == [1, 2, 3]` oldu.
- Düzeltme:
```python
def ekle(x, liste=None):
    if liste is None:
        liste = []
    liste.append(x)
    return liste
```

**2. Lambda'da geç bağlama (late binding)**
- Lambda `i` değerini tanımlandığı anda değil, çağrıldığı anda okur. Çağrıldığında döngü bitmiş olduğu için `i == 2` olur.
- Kanıt: orijinal düğmeler `["2", "2", "2"]` bastı.
- Düzeltme (`i` varsayılan argümanla tanım anında bağlanır):
```python
dugmeler = [lambda i=i: print(i) for i in range(3)]
```
- Düzeltilmiş düğmeler `["0", "1", "2"]` bastı.
