Tek dosya. Bir tarayıcıda aç, W/A/S/D tuşlarıyla küpü hareket ettir. Kamera küpü yumuşak geçişle takip ediyor.

```html
<!doctype html>
<html lang="tr">
<head>
<meta charset="utf-8">
<title>WASD küp + takip kamerası</title>
<style>body{margin:0;overflow:hidden}</style>
<script type="importmap">
{ "imports": { "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js" } }
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x202025);
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 200);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x444444, 2));
scene.add(new THREE.GridHelper(100, 100)); // hareketi görmek için zemin ızgarası

const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: 0x44aa88 })
);
cube.position.y = 0.5;
scene.add(cube);

const keys = {};
addEventListener('keydown', e => keys[e.code] = true); // e.code: klavye düzeninden bağımsız (TR-Q'da da çalışır)
addEventListener('keyup',   e => keys[e.code] = false);

const SPEED = 5;                              // birim/sn
const offset = new THREE.Vector3(0, 4, 8);    // kameranın küpe göre konumu
const dir = new THREE.Vector3();
const camTarget = new THREE.Vector3();
const clock = new THREE.Clock();
camera.position.copy(cube.position).add(offset);

renderer.setAnimationLoop(() => {
  const dt = clock.getDelta();

  dir.set((keys.KeyD ? 1 : 0) - (keys.KeyA ? 1 : 0), 0,
          (keys.KeyS ? 1 : 0) - (keys.KeyW ? 1 : 0));
  if (dir.lengthSq() > 0) cube.position.addScaledVector(dir.normalize(), SPEED * dt);

  camTarget.copy(cube.position).add(offset);
  camera.position.lerp(camTarget, 1 - Math.exp(-5 * dt)); // FPS'ten bağımsız yumuşak takip
  camera.lookAt(cube.position);

  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

- Hareket dünya eksenlerine göre. Küp dönmüyor, kamera da arkasına geçmiyor. Tank tarzı kontrol istersen (A/D ile döndürme, W/S ile baktığı yöne gitme) söyle, ekleyeyim.
- Departman ve frontend-craft akışını kullanmadım. Bu bir proje işi değil, tek dosyalık bir kod örneği. Kodu tarayıcıda da çalıştırıp denemedim.
