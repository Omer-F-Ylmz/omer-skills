GSAP ile yazılmış tek dosyalık örnek. Scroll'a bağlı değil, sayfa yüklenince bir kez çalışır:

```html
<style>
  /* GSAP yüklenmeden başlık bir anlığına görünmesin */
  h1 { visibility: hidden; }
</style>

<h1>Başlık</h1>

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches;

  if (reduce) {
    gsap.set("h1", { autoAlpha: 1 });
  } else {
    gsap.fromTo("h1",
      { y: 40, autoAlpha: 0 },
      { y: 0, autoAlpha: 1, duration: 0.8, ease: "power2.out" }
    );
  }
</script>
```

- `autoAlpha` opaklığı 0'dan 1'e götürür ve `visibility`'yi de kendisi açar. Bu sayede CSS'teki gizleme ilk karede başlığın görünüp kaybolmasını engeller.
- Sistemde hareketi azaltma ayarı açık olan kullanıcılarda başlık animasyonsuz, doğrudan görünür.
- React kullanıyorsan aynı `fromTo` çağrısını `@gsap/react` paketindeki `useGSAP` içine koyman yeterli.

Kodu bir tarayıcıda çalıştırıp denemedim.
