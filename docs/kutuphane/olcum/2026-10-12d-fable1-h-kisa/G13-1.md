**1. `ekle`: değiştirilebilir varsayılan argüman (`liste=[]`)**
Varsayılan liste fonksiyon tanımlandığında bir kez oluşturulur ve her çağrıda aynı nesne kullanılır. Kanıt: `ekle(1)` → `[1]`, sonra `ekle(2)` → `[1, 2]`. Testler aynı süreçte birlikte koşunca birinin eklediği öğeler diğerine sızar.

Düzeltme: varsayılanı `None` yap, çağrı anında yeni liste oluştur.

```python
def ekle(x, liste=None):
    if liste is None:
        liste = []
    liste.append(x)
    return liste
```

**2. `dugmeler`: geç bağlama (late binding) ile döngü değişkeni yakalama**
Lambda `i`'nin değerini değil, `i` değişkeninin kendisini (kapsamı) yakalar. Döngü bittiğinde `i == 2` olur ve üç düğme de çağrıldığında `2` yazar. Kanıt: üç düğme de `2` bastı.

Düzeltme: değeri lambda'nın varsayılan parametresine bağla (bu değer tanımlanma anında sabitlenir).

```python
dugmeler = [lambda i=i: print(i) for i in range(3)]
```

**Doğrulama:** Düzeltilmiş kodda `ekle(1) == [1]` ve `ekle(2) == [2]` assert'leri geçti; düğmeler `0 1 2` bastı.
