**Trace viewer'ı CLI'dan açmak için:**
```
npx playwright show-trace path/to/trace.zip
```
Uzak bir trace'i URL ile de açabilirsin: `npx playwright show-trace https://example.com/trace.zip`

Trace dosyan yoksa önce `npx playwright test --trace on` ile kaydet. Sonra `npx playwright show-report` ile açılan HTML raporundaki trace simgesine tıklayarak da görüntüleyebilirsin.

**Kaynaklar:**
- Trace viewer belgesi: https://playwright.dev/docs/trace-viewer
