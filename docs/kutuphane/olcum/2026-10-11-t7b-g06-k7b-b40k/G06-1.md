En güncel kararlı sürüm **Playwright 1.64.0**. GitHub'da 7 Ekim 2026'da yayınlanmış, npm'de de `latest` etiketi bu sürümde. Bunu `npm view` ve `gh release view` ile kontrol ettim.

Trace viewer'ı CLI'dan açmak için:

```bash
npx playwright show-trace path/to/trace.zip
```

- **Uzaktaki dosya:** Yerel yol yerine trace dosyasının URL'sini verebilirsin: `npx playwright show-trace https://example.com/trace.zip`
- **Kurulum gerektirmeyen yol:** Zip dosyasını https://trace.playwright.dev sayfasına sürükleyip bırakabilirsin. Trace tarayıcıda açılır, sunucuya yüklenmez.
- **Trace yoksa:** Önce trace kaydı oluşturman gerekir. Testi `npx playwright test --trace on` ile çalıştırınca trace dosyaları `test-results/` altına yazılır.

Kaynaklar:
