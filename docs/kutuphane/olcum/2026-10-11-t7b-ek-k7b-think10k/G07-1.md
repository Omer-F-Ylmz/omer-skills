Bu kod 2 m kenarlı bir küp ekliyor ve ona kırmızı Principled BSDF malzeme atıyor. Blender'da çalıştırmadım.

```python
import bpy

# 2 m kenarlı küp (size = kenar uzunluğu)
bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
cube = bpy.context.active_object

# Kırmızı Principled BSDF malzeme
mat = bpy.data.materials.new(name="Kirmizi")
mat.use_nodes = True
bsdf = next(n for n in mat.node_tree.nodes if n.type == 'BSDF_PRINCIPLED')
bsdf.inputs["Base Color"].default_value = (1.0, 0.0, 0.0, 1.0)  # RGBA
mat.diffuse_color = (1.0, 0.0, 0.0, 1.0)  # Solid görünümde de kırmızı görünsün

cube.data.materials.append(mat)
```

Scripting sekmesinde Object Mode'dayken çalıştırın. Blender 5.x'te `use_nodes` artık gerekmiyor, satırı kalsa da sorun olmaz.
