İki yöntem var:

```python
a = [1, 2, 3]

# 1) Listeyi yerinde ters çevirir ve None döndürür
a.reverse()          # a -> [3, 2, 1]

# 2) Yeni bir ters liste döndürür, orijinal liste değişmez
b = a[::-1]
```

Orijinal listeyi korumanız gerekiyorsa `[::-1]` kullanın. Liste kopyalamadan yalnızca ters sırayla dolaşacaksanız `reversed(a)` de işinizi görür.
