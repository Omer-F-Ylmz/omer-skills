# Hesap kuyruğu (KURULUM-REEL-D, kalem 6)

Ömer'in açması gereken hesaplar. Ücretsiz katman bilgisi doğrulanmadı; her biri için açılmadan önce kontrol edilmeli.
Kaynak: `.kos/kopru/kurulum-reel-durum.tsv` (durum = hesap).

| Servis | Kullanım | Ücretsiz katman |
|---|---|---|
| GetLayers (getlayers.ai) | Şablon prompt'u / lisanslı kaynak kodu indirme | doğrulanmadı |
| SiteReel.ai | Site üretimi | doğrulanmadı |
| Sketchfab | CC lisanslı 3B model indirme | doğrulanmadı (indirme hesap ister olabilir) |
| Spline | Community remix + embed | doğrulanmadı |
| Mobbin | UI referans kütüphanesi | ücretli olabilir; doğrulanmadı |

Hesap açılınca: ilgili kaynağın lisansı tekrar okunur, indirilen içerik `docs/kaynak.md` tablosuna girmeden projeye alınmaz.
