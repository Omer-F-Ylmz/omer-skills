# garden-skills — 5 benzersiz kayıt

**Amaç:** Garden eklentileri: içeriği tek dosya HTML makaleye çevirme, GPT Image 2 ile görsel üretimi, yerel bilgi tabanı Q&A, web video sunumları ve görsel/ön yüz tasarımı.

**İç yapı:** Beş [plugin], her biri bir alan: beautiful-article-skills, image-generation-skills, knowledge-base-skills, presentation-skills, web-design-skills.

## En güçlü parçalar
- `beautiful-article-skills` — URL/PDF/DOCX/Markdown/ekran görüntüsünü çevrimdışı dostu tek dosya HTML'e çevirir.
- `image-generation-skills` — GPT Image 2 ve OpenAI uyumlu uç noktalarla görsel üretme/düzenleme.
- `knowledge-base-skills` — Yerel bilgi tabanı arama ve belge Q&A.

## Birlikte kullanım
- beautiful-article-skills + image-generation-skills: makale ve görseller.
- presentation-skills + web-design-skills.

## Tuzaklar
- image-generation-skills OpenAI uyumlu görüntü uç noktası ister; ücretli API olabilir.
- yerel-diger'deki beautiful-article ile çakışır.

## Üyeler
- plugin (5): beautiful-article-skills, image-generation-skills, knowledge-base-skills, presentation-skills, web-design-skills
