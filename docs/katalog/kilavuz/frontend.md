# frontend — 4 benzersiz kayıt

**Amaç:** Ön yüz skill'leri: UI tasarım-uygulama disiplini paketi, React/Next.js kalıpları, HTML slaytlar ve WCAG uyumlu arayüz mühendisliği.

**İç yapı:** Tümü [skill]; paketler (frontend-craft 1 skill'lik, frontend-slides-paket) + rehberler (frontend-patterns, frontend-ui-engineering).

## En güçlü parçalar
- `frontend-craft` — Yön keşfi, DESIGN.md, slop denetimi, vitrin teknikleri paketi.
- `frontend-ui-engineering` — Bileşen, düzen ve WCAG erişilebilirlik gereken arayüz işleri.
- `frontend-patterns` — React, Next.js, durum yönetimi, performans kalıpları.

## Birlikte kullanım
- frontend-craft → frontend-ui-engineering.
- fe ailesi ajanları ve omer-kutuphaneler ile.

## Tuzaklar
- frontend-craft omer-skills'teki frontend-craft eklentisiyle çakışan kopya.
- frontend-slides-paket açıklaması çok kısa; kapsam katalog metninde belirtilmemiş.

## Üyeler
- skill (4): frontend-craft, frontend-patterns, frontend-slides-paket, frontend-ui-engineering
